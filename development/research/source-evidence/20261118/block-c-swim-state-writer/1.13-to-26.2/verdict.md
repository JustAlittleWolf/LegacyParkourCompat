### Independent source conclusion, before witness comparison

The narrow behavior difference is established. Starting with the swim bit true, non-flying/non-spectator, sprint true, and persistent obstruction at either clearance condition, 1.13 can preserve the swim bit when local input lawfully stops sprinting after base-tick reevaluation; on the next tick it again skips the write and the later movement phase still reads swimming. In 26.2, the non-flying player always delegates, and the next base-tick reevaluation clears the prior true bit because sprint is now false. Same-tick ordering is essential: on the first stop tick both versions reevaluate before the local stop; the divergence is on the following tick. This is a bounded source claim, not a trajectory/runtime test.

The report does not identify a concrete block state/shape or prove a normal in-game route into that exact blocked-head precondition; retain it as the stated conditional already-swimming setup, not as a fully demonstrated environmental witness or runtime result. For a true non-flying, non-spectator local player, releasing forward while airborne and not sneaking stops existing swim-sprinting under the cited 1.13 and 26.2 local rules. The pose-fit and pushability predicates were checked separately and do not gate either swim reevaluation.
