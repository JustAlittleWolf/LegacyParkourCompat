The data/resource payload question remains open: these decompiled trees contain Java only, so this audit does not certify packaged default JSON/tag/effect payloads.

The no-finding claim is therefore valid only for the ordinary vanilla input domain; the external-configuration case remains a separate applicability gate, not a proven vanilla default path.
