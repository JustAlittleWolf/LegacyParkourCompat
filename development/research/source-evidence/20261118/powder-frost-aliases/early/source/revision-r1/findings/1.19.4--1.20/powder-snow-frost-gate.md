The same present-support and empty-support branches, including the absent below-cell fallback, are present in this checked release.

Difference: The post-travel `LivingEntity.aiStep()` still removes then conditionally re-adds the transient movement-speed modifier after checking positive frozen ticks. The modifier remains `-0.05F * getPercentFrozen()`, operation `ADDITION`, under UUID `1eaf83ff-7207-4596-b37a-d7a07b3ec4ce`. The non-air block used by `tryAddFrost()` changes. In 1.19.4, the legacy position floors `x`, `y - 0.2F`, and `z`; if that cell is air, it returns the cell below when that block is a fence, wall, or fence gate, otherwise retaining the original cell. In 1.20, a present main supporting block supplies X/Z and the legacy Y calculation, with the support block's position retained for fence/wall/gate support. When support is empty, 1.20 floors position coordinates with the same double-minus-float Y expression but omits the old below-cell fence/wall/gate lookup. `CollisionGetter.findSupportingBlock()` selects from collision positions in the thin footprint-support AABB by squared distance to entity position, with `BlockPos.compareTo` as the tie-break. `checkSupportingBlock()` can clear support when the player is airborne.

Movement meaning: With the same vanilla states and player position, if the legacy foot cell is air, its below cell is a fence/wall/gate, and main support is empty, the old gate reads the below non-air cell while the new gate reads the air cell. With positive frozen ticks and a movement-speed attribute, that changes whether this post-travel update installs the frost slow modifier. The same changed gate source is present in 1.20.2. This establishes the predicate change for the stated input; it does not infer full geometry, a complete trajectory, or runtime parity. Local `getSpeed()` resolves through `LocalPlayer → AbstractClientPlayer → Player` to the movement-speed attribute, but the auto-jump read occurs during travel before the post-travel frost update; a subsequent ordinary read may observe the installed modifier. Exact patch introduction is unknown within 1.19.4–1.20.
