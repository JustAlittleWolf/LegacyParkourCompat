# Powder snow frost gate uses the main supporting block

1.19.4, Mojmap: `1.19.4/mojmap/net/minecraft/world/entity/LivingEntity.java`, `tryAddFrost`, lines 509–524; `1.19.4/mojmap/net/minecraft/world/entity/Entity.java`, `getBlockStateOnLegacy` / `getOnPosLegacy`, lines 720–742 and 1140–1142.
1.20, Mojmap: `1.20/mojmap/net/minecraft/world/entity/LivingEntity.java`, `tryAddFrost`, lines 524–539; `1.20/mojmap/net/minecraft/world/entity/Entity.java`, `checkSupportingBlock` / `getOnPosLegacy`, lines 563–587 and 797–818.
Difference: The frost slow modifier still requires a non-air block state, positive frozen ticks, and a movement-speed attribute, and still adds `-0.05F * getPercentFrozen()` as a transient ADDITION modifier under UUID `1eaf83ff-7207-4596-b37a-d7a07b3ec4ce`. The state used by the non-air predicate changes: 1.19.4 derives the legacy position from floored entity X/Z and `floor(Y - 0.2F)`; 1.20 uses the tracked main supporting block's X/Z when present, with the same legacy Y offset and fence/wall/gate handling. Without a tracked support it retains the floor-X/Z path.
Movement meaning: At a reachable edge or partial-support position where the support block differs from the block at floored player X/Z, the post-travel frost update can read a different non-air state. That determines whether the existing positive-frozen-ticks branch installs the speed modifier; a later local speed read can observe that modifier. Exact patch introduction is unknown within 1.19.4–1.20.
