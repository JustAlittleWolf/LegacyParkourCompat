# Using-item input speed follows use effects
1.21.10, Mojmap: `net/minecraft/client/player/LocalPlayer.java`, `applyInput` lines 612-624 and `modifyInput` lines 627-643.
1.21.11, Mojmap: `net/minecraft/client/player/LocalPlayer.java`, `applyInput` lines 653-665, `modifyInput` lines 668-684, and `itemUseSpeedMultiplier` lines 526-532; `net/minecraft/world/item/component/UseEffects.java`, lines 9-26; `net/minecraft/world/item/Item.java`, `Properties.spear` lines 463-509; `net/minecraft/world/item/Items.java`, spear registrations lines 1897-1916.
Difference: Both versions leave zero movement input unchanged, scale nonzero input by `0.98F`, apply the using-item/non-passenger gate, then apply sneaking speed and square-movement correction. The old version always uses `0.2F` at the held-item step. The new version reads `USE_EFFECTS.speedMultiplier` from the currently used stack, defaulting to `0.2F`; the spear builder sets it to `1.0F` for registered spears.
Movement meaning: During dry, non-riding local movement while using a 1.21.11 spear, forward/strafe input reaches `xxa`/`zza` at the full item-use multiplier before later input modifiers. The 1.21.10 path always applies `0.2F`. Those spear items are new in 1.21.11; this does not assert equal item availability across releases.
