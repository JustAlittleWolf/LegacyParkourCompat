# Blind source audit freeze: fluid movement, 1.20–1.20.1

## Scope and verdict standard

Independent source-only audit of normal, non-riding, non-flying local-player body water/lava admission and height, fluid flow and pushing, eye-fluid state writing/order, and the first ordinary water/lava `LivingEntity.travel` branches reached through `Player.travel`. Comparison assumes the same effective fluid membership and world inputs on both sides. No trajectory or runtime claim is made. Verdicts are bounded to these operations and their listed direct source dependencies; no intermediate patch boundary is established.

**Pair verdict for this roster: no source difference.** Each compared Java payload below has the same SHA-256 in both release roots. The 1.20.1 source manifest entries were independently checked against the files; 1.20 source embedded per-file digests also match their files. Method bodies are intact and byte-identical across the pair.
