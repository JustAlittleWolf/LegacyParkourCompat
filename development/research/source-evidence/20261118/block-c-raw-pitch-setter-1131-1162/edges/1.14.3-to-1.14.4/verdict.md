## Compared behavior

### Ordinary local turn

* 1.14.3 Yarn `Entity.changeLookDirection(double,double)`, `Entity.java:314–326`.
* 1.14.4 Feather `Entity.updateLocalPlayerCamera(double,double)`, `Entity.java:317–328`; cross-check: Mojmap `Entity.turn(double,double)`, `Entity.java:319–328`.

The operations correspond exactly: multiply the vertical delta by `0.15` and the horizontal delta by `0.15`; add each to current pitch/yaw and narrow each sum to `float`; clamp current pitch to `[-90.0F, 90.0F]`; add the same deltas to previous pitch/yaw with the same float narrowing; clamp previous pitch to the same bounds; then notify the vehicle/passenger callback. The mappings rename fields and the callback, but do not change arithmetic, casts, clamp placement, or write order. Neither output introduces a clamp for yaw.

### Reachable dry active Elytra movement

* 1.14.3 Yarn `LivingEntity.travel(Vec3d)`, `LivingEntity.java:1779–1819`; the living tick calls it at line 2220. The local-player Elytra-start path is `ClientPlayerEntity.java:696–703`.
* 1.14.4 Feather `LivingEntity.moveRelative(Vec3d)`, `LivingEntity.java:1786–1825`; its living tick calls it at line 2227. Mojmap cross-check: `LivingEntity.travel(Vec3)`, `LivingEntity.java:1782–1822`, called at line 2223. Local-player Elytra-start path is `LocalPlayer.java:707–714`.

For an active fall-flying player in neither water nor lava (with ordinary non-flying abilities), both branches reach Elytra movement. Both read current pitch to form `l = pitch * (float)(Math.PI / 180.0)`, derive the current look vector from current pitch/yaw with the same float trigonometric sequence, calculate the cosine-based lift factor, then use the same sine-based dive term and subsequent velocity adjustments. Thus the local turn's current pitch feeds the same Elytra consumer. Previous pitch is updated in the same place/order for interpolation, while this movement branch reads current pitch. The source shows a reachable player path, but this is static source evidence, not a trajectory prediction or runtime parity result.
