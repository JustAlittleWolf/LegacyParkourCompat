## Source findings

- **Snow geometry:** In all inspected versions `LAYERS` is an integer property from 1 through 8. The upper value 1 collision box uses `(LAYERS - 1) * 0.125F` (1.8–1.8.8) or the equivalent local-box max-Y calculation (1.9–1.10.1), yielding `maxY=0` at the upper block base plane. In 1.9+, the positive 1/8 outline shape is separate; the collision box is rebuilt with the zero max-Y for `LAYERS=1`.
- **Legal support boundary:** 1.8 uses `below == this && below.LAYERS == 7`; it therefore rejects a lower state whose property is 8. Starting at 1.8.1, the predicate is `below == this && below.LAYERS >= 7`, so state 8 is admitted. All requested 1.8.2–1.10.1 releases retain this admitting predicate. This is the sole blocker for the precisely specified legal witness in 1.8.
- **Strict collection:** The ordinary movement collector calls the block collision path for cells in the movement query. The snow box is non-null. The collision collector appends it only when query `intersects` the box; the AABB predicate uses strict inequalities, so a zero-height Y interval is admitted only if `query.minY < plane < query.maxY`. With the stated straddling condition, it is retained.
- **Descending clip:** The ordinary entity `move` routine obtains collision boxes from the entity AABB expanded by requested `(dx,dy,dz)`, then applies each `intersectY` to the current box and negative `dy`. The negative branch clamps when the entity bottom is at/above obstacle top, replacing the requested negative displacement with `plane - box.minY`; the player follows this entity movement path. This confirms only the requested ordinary vertical witness, not whole-tick parity.
- **Patch changes within the audited scope:** 1.8.1 changes the support comparison from exact `== 7` to `>= 7`, making `LAYERS=8` legal. 1.8.2–1.8.8 retain matching consulted-member hashes across all five files. SnowLayerBlock and Block hashes match across 1.9–1.9.2; 1.9.3 changes those source files, and 1.10/1.10.1 change them again, but the inspected geometry, placement, collector, strict AABB and vertical-clip behavior remains as stated.
