## Bounded trace and comparison

- `decompiled_minecraft/1.11.1/ornithe-feather/net/minecraft/entity/living/mob/passive/animal/LlamaEntity.java:60-63,144-156` and the corresponding 1.11.2 path at the same lines: the default constructor sets `(0.9F, 1.87F)` dimensions. The Llama file bytes are identical across the pair (SHA-256 `1577cf77a5c1d0e47dde0e13327dc333fcd65aa86c7e9073f49b2c678f0257b1`). `updateRiderPositon(Entity)` gates on `this.hasPassenger(rider)`, computes yaw sine/cosine into floats, declares the unused `float h = 0.3F`, then calls `rider.setPosition(...)`. Its Y argument in both releases is exactly `this.y + this.getMountHeight() + rider.getRideHeight()`.
- In that class, `getMountHeight()` returns `this.height * 0.67` (double literal; `height` is float). For the default adult Llama, `height` is `1.87F`, so the mount-height multiplication is promoted to double. The Y argument is a left-associative double sum: `this.y + (this.height * 0.67D) + rider.getRideHeight()`.
- `decompiled_minecraft/1.11.1/ornithe-feather/net/minecraft/entity/living/player/PlayerEntity.java:379-398,948-950` and the corresponding 1.11.2 ranges match: `getRideHeight()` returns double `-0.35`; `rideTick()` has a `!world.isClient && isSneaking() && isRiding()` stop-riding/clear-sneak gate, otherwise delegates to `super.rideTick()`.
- `decompiled_minecraft/1.11.1/ornithe-feather/net/minecraft/entity/Entity.java:1569-1582,2355-2361` and the corresponding 1.11.2 ranges `1556-1569,2342-2348` match in the relevant bodies. Parent `rideTick()` stops if the mount was removed; otherwise zeroes all three velocity components, ticks the rider, then calls the mount callback if still riding. `hasPassenger` scans the passenger list and compares with `equals`. There is no logical-side gate in Llama’s callback itself.

Consequently the reachable direct local player Y write and its arithmetic order, primitive types, membership gate and rider-call ordering do not differ in this bounded source slice. No finding is warranted for this operation. Mount/non-player movement and other vehicles remain outside this verdict.
