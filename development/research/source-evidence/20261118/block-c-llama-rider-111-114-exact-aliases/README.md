# Early Llama rider Y placement (2026-11-18)

This receipt preserves nine independently audited exact-source comparisons of the direct rider Y-placement operation for an ordinary adult/default Llama carrying one local Player passenger. It records the Y expression and callback path only; it does not cover vehicle physics or non-player movement. TraderLlama applicability is included only at the 1.14 endpoint where the audit checked its inheritance. Adjacent endpoint results do not establish an unexamined patch boundary or full movement-pair coverage.

The operation is the Llama callback's ordered position write: mount Y plus mount height plus player ride-height offset, using the exact source numeric types and dispatch path documented in each report/verdict. All nine verdicts accept bounded no-difference for their reviewed pair and operation.
