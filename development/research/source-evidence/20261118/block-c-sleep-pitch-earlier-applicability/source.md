# Pre-1.13 sleeping pitch source gate

Assignment: close source-body coverage for every available stable release from 1.8 through 1.12.2 in canonical Ornithe Feather sources, focused on a `LivingEntity` sleeping-conditioned zero-pitch write after travel. No product, Git, wiki, or runtime sources were inspected. All source copies are byte-for-byte copies of the canonical files; hashes are SHA-256.

## Result

All 24 available stable IDs have local Feather mapping/source provenance and a matching `LivingEntity.java` source digest. None has a sleeping-conditioned `pitch = 0.0F` assignment. Across each complete `LivingEntity.tick()` body, there is no `isSleeping()` call or pitch-zero assignment. The only `isSleeping()` occurrence in each whole class is its predicate declaration. The only exact `pitch =` writer in each class is interpolation from `lerpPitch`, not a sleep-conditioned reset; it is outside `tick()` and belongs to entity update interpolation.

Therefore the reset is absent throughout 1.8–1.12.2. The accepted anchors remain 1.13.2 Feather absent and 1.14.0 Feather present from the immutable prior audit; the exact introduction remains bounded after 1.13.2 and no later than 1.14.0. In the 1.14 source the reset runs after `tickMovement()` and has no logical-side gate.

## Method and gate check

The comparable direct pitch writer is the lerp interpolation assignment; it is not a sleeping reset.
