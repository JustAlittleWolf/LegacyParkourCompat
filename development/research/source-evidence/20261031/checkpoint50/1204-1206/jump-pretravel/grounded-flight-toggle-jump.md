# Grounded flight-toggle jump
1.20.4, Mojmap: `net/minecraft/client/player/LocalPlayer.java`, `aiStep`, lines 717–734.
1.20.5, Mojmap: `net/minecraft/client/player/LocalPlayer.java`, `aiStep`, lines 720–741.
Difference: Inside `getAbilities().mayfly`, when the game mode is not always-flying, the rising-edge gate is `!$$0 && this.input.jumping && !$$4` in 1.20.4 and `!$$0 && this.input.jumping && !$$5` in 1.20.5. It arms `jumpTriggerTime = 7` if zero; on a later rising edge while the timer is nonzero, the `!this.isSwimming()` branch toggles flight. 1.20.5 then calls `jumpFromGround()` only when the toggle enabled flight (`$$3.flying`) and `this.onGround()` is true; 1.20.4 only toggles flight, updates abilities and resets the trigger timer.
Movement meaning: A grounded LocalPlayer double-tapping jump to enter flight now invokes the player ground-jump routine before abilities are updated. Under its computed-power gate (`!($$0 <= 1.0E-5F)`), the routine writes vertical movement and sets `hasImpulse`; it adds horizontal sprint impulse only if `this.isSprinting()`. Toggling flight off or enabling it while airborne does not call the routine. The jump uses the 1.20.5 `LivingEntity.jumpFromGround` behavior described in `jump-strength-attribute-and-execution-gate.md`.
