# Bed wake selects a different stand-up position

1.16.1 (Mojmap): `net/minecraft/world/level/block/BedBlock.java`, `findStandUpPosition` (227–254) scans the x/z grid and calls `getStandingLocationAtOrBelow` (257 onward), which searches downward through empty shapes, adds `2.0E-7` to support Y, checks the vertical limit, then uses `noCollision` and rejects candidates whose AABB expanded down by `0.2F` contains a block dangerous to the entity type (285–287). Air and stone pass that extra gate for the stated witness. `net/minecraft/world/entity/LivingEntity.java`, `stopSleeping` (3021) calls this path and applies the selected position.
1.16.2 (Mojmap): `BedBlock.findStandUpPosition` (233–244) adds yaw-dependent candidate ordering and calls `findStandUpPositionAtOffset` (276–290); `net/minecraft/world/entity/vehicle/DismountHelper.java`, `findSafeDismountLocation` uses `BlockGetter.getBlockFloorHeight(VoxelShape,Supplier)` to select support height and checks candidate collision and dangerous-block gates (82–98); air and stone pass for the stated witness. `LivingEntity.stopSleeping` (3037) passes yaw to the new search and commits the result. The method forms persist unchanged through 1.16.5. Boundary: 1.16.1 → 1.16.2.

Difference: For a north-facing non-bunk bed at `(0,64,0)` over a level stone floor with air in the adjacent candidate cells, the old grid scan first accepts `(-0.5,64.0000002,-0.5)`. The new yaw-ordered search first accepts either west center `(-0.5,64,0.5)` or east center `(1.5,64,0.5)`, depending on player yaw. Both endpoints' player boxes clear the bed and stone support. The result is a different horizontal stand-up cell and a `2.0E-7` Y difference. Attribute this to the complete paired bed search and support algorithms, not to the new helper alone.

Movement meaning: The existing client bed-wake response reaches `Player.stopSleepInBed(false,false)` and `LivingEntity.stopSleeping`; the local player commits the selected position with `setPos`. Bed exit placement therefore changes the local player's position directly. Bed-entry eligibility is outside this finding.
