The 1.8 `MovingBlock` uses a defensive copy where 1.7.10 edits the moved block's returned `Box`. I found no distinct returned bounds for this provider operation. Because this is a mutable object side-effect, a broader alias audit would be needed before claiming the two providers identical under arbitrary shared-object providers; this report makes no claim about a nonstandard aliased provider or about moving-block production.

## Result and boundary

No new player movement geometry delta was established in this owned class slice. Piston/head and moving-block results are collision inputs to the ordinary query if such world/block states are already present; production of those states and piston movement physics are outside this assignment. The result covers these eleven classes only; it is not a complete provider inventory or pair-freeze claim.
