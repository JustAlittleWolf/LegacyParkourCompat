# Flying vertical input uses configured fly speed

1.7.10, Ornithe Feather: `net/minecraft/client/entity/living/player/InputClientPlayerEntity.java`, `mobTick`, lines 197–205.
1.8, Ornithe Feather: `net/minecraft/client/entity/living/player/LocalClientPlayerEntity.java`, `mobTick`, lines 604–612; `net/minecraft/entity/living/player/PlayerAbilities.java`, `flySpeed` default/accessor, lines 11, 44–49.
Difference: While flying, the active local camera player applies sneak/jump vertical input as a fixed double `0.15` subtraction/addition in 1.7.10. In 1.8 the writes are gated by `isCamera()` and use `getFlySpeed() * 3.0F`; multiplication is performed in float precision before promotion to the double velocity. Both ability classes initialize the float to `0.05F`, so the default 1.8 adjustment is `0.15000000596046448` rather than double `0.15`; a non-default configured speed scales the adjustment. The ability default and accessor are otherwise identical.
Movement meaning: With flying enabled and only jump or sneak held by the active local camera player, 1.8 adds/subtracts the configured-speed float product before superclass travel, while 1.7.10 adds/subtracts fixed double `0.15`. The operation/type difference is source-confirmed; accumulated position divergence is a predicted trajectory effect. The 1.8 camera guard concerns the later detached-camera path and is not part of ordinary active-camera movement.
