## Source-boundary status and blockers

For the uncovered respawn correction, the evidence supports an old-side emulation entry at 1.20.6 as the bounded endpoint, with 1.21+ native behavior. **The exact first patch release that changed this behavior is not established**; a production range across intervening releases needs exact-source checks before claiming a patch cutover. The three already-covered changes also cite 1.20.5 as their implementation annotation because their older behavior is shared with that release, while this audit only accepts the 1.20.6→1.21 transition. No candidate was prepared or integrated, per assignment.

No technical/source blocker remains for this bounded reconciliation. Open integration work is only the unimplemented respawn jump-strength operation and its precise intermediate release boundary; these are deliberately not implemented here.
