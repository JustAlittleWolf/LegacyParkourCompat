# Relative movement trigonometric lookup precision
1.21.10, Mojmap: `decompiled_minecraft/1.21.10/mojmap/net/minecraft/util/Mth.java`, `sin(float)`/`cos(float)` lines 48-53 and `SIN` initialization lines 32-36; `net/minecraft/world/entity/Entity.java`, `moveRelative`/`getInputVector` lines 1590-1605.
1.21.11, Mojmap: `decompiled_minecraft/1.21.11/mojmap/net/minecraft/util/Mth.java`, `sin(double)`/`cos(double)` lines 50-56 and `SIN` initialization lines 34-38; `net/minecraft/world/entity/Entity.java`, `moveRelative`/`getInputVector` lines 1608-1623.
Difference: In 1.21.10 the float-angle `getInputVector` calls the float `Mth` overloads, which multiply by `10430.378F`, cast to `int`, and mask with `65535` before indexing a `float[65536]`. In 1.21.11 the same float angle expression is widened at the call to the double overload; that overload multiplies by `10430.378350470453`, casts to `long`, masks with `65535L`, then casts the masked index to `int`. `SIN` remains a `float[65536]`; its initializer also changes from `(float)Math.sin(index * Math.PI * 2.0 / 65536.0)` to `(float)Math.sin(index / 10430.378350470453)`. `Entity#getInputVector` still computes the angle using float operands, then uses its sine and cosine to construct the X/Z components. The examined earlier Mojmap directories from 1.16.2 through 1.21.10 use the float overload and float-scaled lookup; see `comparison.md` for every assigned release and exact excerpts.
Movement meaning: `Entity#moveRelative` supplies the entity yaw to `getInputVector`; `LivingEntity` calls `moveRelative` during travel. When a player input vector passes the `lengthSqr() < 1.0E-7` early return, the new lookup arithmetic can change the sine/cosine values used to rotate the scaled input into world-space X/Z movement. This finding describes the source arithmetic only; it does not claim a specific trajectory delta.

Evidence note: Root-level `mojmap.provenance.json` and `mojmap.ready.json` are absent for 1.16.3, 1.16.4, 1.17, 1.21.2, 1.21.6 and 1.21.7. Their hidden `mojmap/.decompile-provenance.json` records provide version-specific client, mapping and version-metadata input hashes; their embedded Mth and Entity hashes match the published source files. Full identities and excerpts for these releases are recorded in `comparison.md`.

Coverage boundary: 1.21.9 and releases before 1.16.2 were not assigned or inspected. The evidence establishes the float lookup in every assigned release through 1.21.10; it does not establish the lookup for 1.21.9, the exact transition between 1.21.8 and 1.21.10, or that 1.16.2 is the earliest historical release using it.
