The sibling `evidence.sha256.txt` records the paired ready and provenance marker hashes, verified source and artifact manifest hashes, published client and version metadata hashes, and source hashes checked against the source manifests. The client packet handler forwards the event on the client thread. Event ID 1 sets the open count and sets the state to opening for count 1 or closing for count 0. The client's unpaused tick runs entity ticks before block-entity ticks. Tick-rate and block tick permission, active bound ticker, border and valid block state gate the callback. Box ticker registration accepts both logical sides. A valid client block entity therefore reaches the opening branch when supplied the opening block event.

The animation snapshots the previous `float` progress, adds `0.1F` during opening, calls neighbor updates when the old value was zero, and clamps to `1.0F` and updates neighbors at completion before requesting displacement. Both first and terminal opening ticks can displace. Closing subtracts `0.1F`, handles its neighbor updates and lower clamp, and performs no direct push. The regular box bounds use a separate `0.5F * getProgress(1.0F)` input.

The push path requires a shulker-box block state and uses its `FACING`. It passes the old and current progress directly, without a half-height factor, to `getProgressDeltaAabb(1.0F, …)`. The symmetric unit bounds at bottom center expand by the signed direction steps times the promoted `float` maximum progress times size. They then contract by the negated steps times `(1.0 + minProgress)` times size and translate to the block bottom center. The old `pos.getBottomCenter()` delegates to the exact static call used in 26.2. Both produce doubles from coordinate plus `(0.5, 0.0, 0.5)` in the same order. The query visits accessible, nonempty entity sections and requires strict AABB intersection. Its default selector excludes spectators, the excluded-entity argument is null, and the subsequent push-reaction gate admits the player through inherited `NORMAL`. Each request component is computed in double precision as `(translatedAabbAxisSize + 0.01) * directionAxisStep` in X/Y/Z order. The size getters subtract the translated endpoints. Collapsing the calculation to the difference of the float progresses would omit the original rounding.

A non-spectating local player moving into the slab swept by an already-opening box before the block-entity phase gets `move(SHULKER_BOX, delta)`; the regular collision shape and the swept query use distinct progress inputs. The player wrapper measures actual horizontal displacement after the superclass move, casts each to `float`, runs auto-jump and accumulates walked distance. `SHULKER_BOX` bypasses the `PISTON`-only per-axis limit and the `SELF`/`PLAYER` edge backoff. Both versions can apply and clear a pending stuck-speed multiplier, clip against collision, write position, and update collision and ground state.

**Shared dependency.** The movement path has no shulker-box filter around post-collision response. For the local player, 26.1.2 `Entity.move` 773–786 explicitly zeros colliding horizontal velocity components and invokes the effect block's fall-on movement hook on vertical clipping when movement can be simulated. 26.2 `Entity.move` 781–786 and `restituteMovementAfterCollisions` 802–843 dispatch restitution for a simulated horizontal collision or a clipped nonzero vertical request. The 26.2 shared path obtains restitution from entity/block properties and the suppresses-bounce gate, applies per-axis restitution, and for positive vertical restitution incorporates consumed movement divided by current vertical velocity, gravity and interpolated air drag. It consequently reaches different velocity logic if the box request clips. Keep the finding and dependencies for this operation in the shared collision-response slice, including block restitution, tags, fall/step handling and other callers. The inherited obstacle-query/shape and auto-jump flows beyond the local wrapper are shared dependencies of the consumer. No claim of final player state parity follows from this slice.
