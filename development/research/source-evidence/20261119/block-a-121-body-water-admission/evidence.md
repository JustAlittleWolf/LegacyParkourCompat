## Paired source observations

- `Entity.updateFluidHeightAndDoFluidPushing(TagKey<Fluid>, double)` first calls `touchingUnloadedChunk()` and returns `false` if it reports true. Otherwise it deflates the entity box by `0.001`, scans integer coordinates `floor(min)` inclusive to `ceil(max)` exclusive, checks the requested fluid tag, calculates `double surface = blockY + fluidState.getHeight(...)`, and admits the cell when `surface >= deflatedBox.minY`. `FluidState.getHeight` returns `float`, so Java evaluates `int + float` as `float` before widening the result into the `double` local. The surface comparison is inclusive.
- `Entity.touchingUnloadedChunk()` inflates the entity box by `1.0`; floors minX/minZ, ceils maxX/maxZ; and negates `level().hasChunksAt(minX,minZ,maxX,maxZ)`.
- `LevelReader.hasChunksAt(int,int,int,int)` converts the passed block coordinates to section/chunk coordinates and loops both endpoints inclusively, dispatching each check through `this.hasChunk(x,z)`. `ClientLevel.hasChunk(int,int)` overrides this to unconditionally return `true` in all eleven exact source sets.
