## Source-confirmed differences and drafts

Three small candidate finding drafts are in this folder:

- `drafts/diagonal-collision-axis-order.md` — in the newer collision resolver, when both horizontal deltas are nonzero, horizontal clipping begins with the smaller-magnitude axis; the older resolver always clips X then Z after Y. The player-reachable source gate is diagonal movement; a collision configuration where first-axis clipping changes available overlap can change the resolved vector. This is a source-confirmed operation-order difference, with a concrete runtime/map witness still needed.
- `drafts/lava-contact-state.md` — old lava mode is an immediate material scan over the entity box contracted by `(0.1,0.4,0.1)`; new `isInLava` reads a flag reset on every `Entity.move` and set by an interior block-contact scan inset only `0.001` when a LiquidBlock fluid is tagged LAVA. This changes the sampled region and update timing for the next travel branch.
- `drafts/stacked-fluid-height.md` — old flow-fluid height is `level / 9.0F`; new height is `1.0F` whenever the fluid directly above is the same fluid, otherwise the same level-derived height. Entity water-contact and eye-submersion checks consume this height, so stacked water can move their upper-surface threshold.

The exact intermediate patch where any difference entered remains unknown; this endpoint comparison does not cover 1.13.2→1.14.4 internal patch boundaries. Source acceptance, independent audit, runtime parity and implementation readiness are not established.
