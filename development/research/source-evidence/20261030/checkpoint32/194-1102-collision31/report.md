## Candidate source difference
`farmland-collision-shape.md`: 1.9.4's `FarmlandBlock.getCollisionShape` explicitly returns `FULL_BLOCK_SHAPE` although its visual `getShape` is 15/16 high. In 1.10.2 the override is removed and the unchanged superclass default delegates collision shape to that 15/16 `getShape`. This changes the collision surface for a player descending onto farmland. Exact intermediate introduction point is unknown within the 1.9.4→1.10.2 interval.
