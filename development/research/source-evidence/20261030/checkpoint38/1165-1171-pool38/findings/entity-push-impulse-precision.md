# Entity push impulse square-root precision

1.16.5, Mojmap: `net/minecraft/world/entity/Entity.java`, `push(Entity)`, lines 1180–1207; `net/minecraft/util/Mth.java`, `sqrt(double)`, lines 37–39; `net/minecraft/client/player/RemotePlayer.java`, `tick` and `aiStep`, lines 35–76; `net/minecraft/world/entity/LivingEntity.java`, `pushEntities` and `doPush`, lines 2502–2524 and 2549–2551; `net/minecraft/world/entity/EntitySelector.java`, `pushableBy`, lines 28–55.
1.17.1, Mojmap: `net/minecraft/world/entity/Entity.java`, `push(Entity)`, lines 1278–1303 and `push(double,double,double)`, lines 1309–1312; `net/minecraft/client/player/RemotePlayer.java`, `tick` and `aiStep`, lines 35–70; `net/minecraft/world/entity/LivingEntity.java`, `pushEntities` and `doPush`, lines 2614–2636 and 2661–2663; `net/minecraft/world/entity/EntitySelector.java`, `pushableBy`, lines 28–55.
Difference: after the existing `absMax(dx,dz) >= 0.01F` gate, 1.16.5 stores `Mth.sqrt(f)`'s float result in the double divisor, while 1.17.1 uses `Math.sqrt(f)` as double. For local-player and nearby remote-player center differences `(dx,dz)=(0.25,0.5)`, both 0.6F-wide player boxes overlap in both axes and the gate passes. With the remote player’s default `pushthrough=0`, the local player's X impulse term is `0.01767767009562193` in 1.16.5 and `0.01767766979308149` in 1.17.1, using the same `0.05F` factor; this expression-level witness is not a runtime trace.
Movement meaning: the client-side `RemotePlayer.tick` reaches the virtual `RemotePlayer.aiStep`, which calls `pushEntities`. The client `pushableBy` predicate admits the local player candidate. `doPush` invokes `localPlayer.push(remotePlayer)`, and the changed computed impulse is added to the local player's delta movement. This operation occurs on the other player's client tick and changes local-player velocity.
