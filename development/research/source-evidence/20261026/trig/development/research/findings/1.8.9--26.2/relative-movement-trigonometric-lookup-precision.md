# Relative movement trigonometric lookup precision
1.8.9, ornithe-feather: 1.8.9/ornithe-feather/net/minecraft/util/math/MathHelper.java:14-19,392-395; relative input rotation at 1.8.9/ornithe-feather/net/minecraft/entity/Entity.java:844-859.
26.2, published unobfuscated: 26.2/unobfuscated/net/minecraft/util/Mth.java:34-38,50-55; Entity.moveRelative/getInputVector at net/minecraft/world/entity/Entity.java:1746-1760.
Difference: the older sine table contains 65536 floats generated with (float)Math.sin(index * Math.PI * 2.0 / 65536.0). Its sin/cos accept float radians, multiply by 10430.378F in float, add 16384.0F for cosine in float, truncate to int and mask with 65535. In 26.2 the table generator uses index / 10430.378350470453; sin/cos accept double, multiply by that double scale, add 16384.0 in double for cosine, truncate to long, mask with 65535L, then cast to int. The player input caller still computes yaw radians with a float multiplication; widening occurs at the trig invocation. In 1.8.9 only, the caller first multiplies yaw by float PI and then divides by 180F, a separate difference.
Movement meaning: ordinary nonzero forward input at yaw -45F reaches this rotation. Both yaw conversion forms produce float radians -0.7853981852531433. Old cosine index is 8192 (float scaled value rounds to exactly -8192 before adding 16384), whereas 26.2 cosine index is 8191 (double sum is just below 8192). The sine index is 57344 in both. The selected cosine values are approximately 0.7071067690849304 and 0.7070389986038208, respectively. Thus forward input contributes a different Z acceleration without unusual yaw magnitudes, fluids, equipment or sprinting. For example an airborne unsprinting player may supply horizontal forward input 0.98F and scale 0.02F; those inputs clear each method's nonzero threshold. This is a source arithmetic consequence, not a gameplay parity measurement.
Boundary: exact adjacent stable releases 1.21.10 and 1.21.11 establish the new trig indexing and table-generation expressions first appear in stable 1.21.11. Inspected 26.1 and 26.2 retain the latter formulas. This does not date a snapshot introduction. The changed table-generation expression is recorded as evidence; no separate observable movement difference is claimed solely from its rewrite.
