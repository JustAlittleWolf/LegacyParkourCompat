# Client fall-distance updates are suppressed in 1.21.4

1.21.3, Mojmap: `1.21.3/mojmap/net/minecraft/world/entity/Entity.java`, `move` 639-672, `checkFallDamage` 1216-1231, `isControlledByLocalInstance` 3149-3151; `LivingEntity.java`, `checkFallDamage` 341-373; `player/Player.java`, `maybeBackOffFromEdge` 1066-1124 and `isControlledByClient` 2146-2148; `client/player/LocalPlayer.java`, `isEffectiveAi` 478-480.

1.21.4, Mojmap: `1.21.4/mojmap/net/minecraft/world/entity/Entity.java`, `move` 647-682, `checkFallDamage` 1237-1252, `isControlledByLocalInstance` 3173-3175; `LivingEntity.java`, `checkFallDamage` 339-371; `player/Player.java`, `maybeBackOffFromEdge` 1069-1127 and `isControlledByClient` 2166-2168; `client/player/LocalPlayer.java`, `isEffectiveAi` 483-485, `isShiftKeyDown` 593-595.

Difference: 1.21.4 adds `&& !this.isControlledByClient()` to the entire `Entity.move` call gate for `checkFallDamage`. Player returns true, so this suppresses both airborne `fallDistance -= (float) movementY` and the grounded reset. It does not merely retain a previously accumulated ordinary fall distance at landing. Starting from zero, an otherwise ordinary dry client fall accumulates positive float distance in 1.21.3 but remains zero in 1.21.4. `LivingEntity.checkFallDamage` delegates to Entity; the separate `doCheckFallDamage` callers are server packet handlers, not a replacement client accumulator.

Movement meaning: the unchanged crouching edge-backoff consumer reads this state before collision. Its airborne gate is `fallDistance < maxUpStep() && !canFallAtLeast(0, 0, maxUpStep() - fallDistance)`. For a player falling more than the default step height toward a finite lower floor, the 1.21.3 distance can disable backoff while 1.21.4's zero can enable it. A conditional seven-tick numeric caller-state trajectory is retained in the accompanying evidence. It changes horizontal movement while both players remain airborne. Its chosen initial horizontal momentum has not been reconstructed from a complete preceding ordinary-input history; therefore this finding establishes the changed ordinary-fall state write and conditional movement consequence, not a fully closed from-rest gameplay witness.

The skipped-accumulator behavior is bounded to 1.21.4 among the inspected stable releases. 1.21.5, Mojmap: `Entity.java` 702-703 and 3162-3169, `player/Player.java` 1312-1314 and `client/player/LocalPlayer.java` `isLocalPlayer`, restore the client callback through `isLocalInstanceAuthoritative()`. 26.2, published unobfuscated: `Entity.java` 777-778, 1553-1574 and 3589-3595, `player/Player.java` 1281-1283, retain that restored client path. The independent float-to-double storage change at 1.21.5 is not part of this suppression claim.
