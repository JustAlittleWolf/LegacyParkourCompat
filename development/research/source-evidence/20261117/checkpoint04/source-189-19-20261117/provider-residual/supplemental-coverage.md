## Result

No independent player collision-shape delta was found in the examined residual providers. Static bounds and state-dependent player-collision bounds are equivalent across the pair where collision is enabled. The expected distinction from 1.8.9 mutable world-space bounds to 1.9 local state shapes is accounted for by `Block.addCollisions`: 1.8.9 `Block.java` `addCollisions`/`getCollisionShape` (339–350) returns/intersects world-space boxes; 1.9 `Block.java` `addCollisions`/`addCollision`/`getCollisionShape` (313–328) translates local boxes before intersection. Empty collision sentinels remain empty through the corresponding class overrides.

## Coverage, dependencies, and stop state

- Examined the residual collision-provider inventory from the source-only supplement: all listed remaining classes except assigned exclusions. The `AirBlock` provider is also confirmed no-collision: 1.8.9 `AirBlock.java` `getCollisionShape` (18–23), 1.9 `getCollisionShape` (20–25). `MovingBlock` is excluded as above.
- Callback scan of residual provider classes found no new player-velocity/fall-state callback delta. `StairsBlock.onSteppedOn` delegates to its base block in both releases (1.8.9 lines 468–469; 1.9 lines 219–220), already recorded by the supplemental report. `LilyPadBlock` adds a boat-only removal callback in 1.9; boat behavior is outside this player-on-foot scope. Other callback behavior is inherited and no player-specific movement response is added here.
- State-input dependencies still require caller closure for state-driven shapes (`Anvil`, `Chest`, `Cocoa`, `Skull`, `Stem`) if the relevant provider can receive a state inconsistent with the world state. The provided source slice establishes their getter formulas but not every caller's state/world identity.
- Multipart clipping dependency remains open for stairs; the assigned travel-resolver owner must establish exact per-box clipping behavior before the stair geometry comparison can be fully closed.
- Finding drafts: none. This closes only this provider-residual coverage slice; it does not freeze or audit the full release pair.
