## Player movement callback inventory

Callsites and block overrides were checked in both versions; all named `Block`, `Entity`, `LivingEntity`, `World`, and block-package callback bodies are identical across the pair, with one unrelated `PlayerEntity` metadata literal difference noted at the end.

- Movement collision query: `Entity.move` calls `World.getCollisions` for sneak-edge support, axis resolution and step-up (`net/minecraft/entity/Entity.java:441-625`); `World.getCollisions` dispatches block providers at `World.java:899-1018`.
- Pre-contact response: `Entity.move` calls `Block.beforeCollision` (`Entity.java:656`); `SlimeBlock.beforeCollision` is the sole block override (`net/minecraft/block/SlimeBlock.java:34`), with base no-op at `Block.java:631`.
- Ground contact: `Entity.move` calls `Block.onSteppedOn` only when the block below is non-null and entity is on ground (`Entity.java:667-668`). Overrides: `RedstoneOreBlock:42`, `SlimeBlock:46`, `StairsBlock:220`; base no-op `Block:512`. Slime changes horizontal velocity for low vertical speed and non-sneaking entities; Stairs delegates to its base block.
- Block overlap: `Entity.checkBlockCollisions` traverses blocks intersecting the inset entity box and calls `Block.onEntityCollision` (`Entity.java:737-750`). Overrides: `AbstractPressurePlateBlock:101`, `ButtonBlock:213`, `CactusBlock:98`, `CauldronBlock:69`, `CobwebBlock:27`, `DetectorRailBlock:56`, `EndPortalBlock:63`, `LilyPadBlock:30`, `PortalBlock:170`, `SoulSandBlock:28`, `TntBlock:103`, `TripwireBlock:134`; base no-op `Block:536`. Player movement responses among these include cobweb state (`CobwebBlock` → `Entity.onCobwebCollision`, base `Entity.java:1744`; `PlayerEntity` override at `PlayerEntity.java:1500` suppresses it while flying) and soul-sand horizontal velocity scaling (`SoulSandBlock:28-30`). Other listed callbacks trigger block/world behavior or fall under excluded damage/portal transfer outcomes; none differs in this pair.
- Landing/fall callback: `Entity.updateFallState` calls `Block.onFallenOn` (`Entity.java:798`); overrides are `FarmlandBlock:67`, `HayBlock:19`, and `SlimeBlock:25`; base `Block:627`. Slime has a direct velocity-bounce response; farmland/hay alter fall-damage behavior. No method differs.
- Fluid drag: `Entity.checkWaterCollisions` calls `World.applyLiquidDrag` (`Entity.java:849-855`); `World.applyLiquidDrag` dispatches to `Block.applyMaterialDrag` (`World.java:1560-1585`). Overrides are `LiquidBlock:175` and `StairsBlock:189` (stairs delegates to its base block); base is `Block:522`. All are unchanged.
- Player/entity overlap: `PlayerEntity` tick builds an overlap box and calls its private collision helper (`PlayerEntity.java:447-468`), which calls the other entity's `onPlayerCollision`; base `Entity.onPlayerCollision` is at `Entity.java:1058`. `PlayerEntity.push` override is at `PlayerEntity.java:1886`. The related files are source-identical except for the metadata literal below.
- Moving-block direct response: `MovingBlockEntity.moveEntities` finds intersecting entities and applies displacement via `Entity.move` (`net/minecraft/block/entity/MovingBlockEntity.java:90-145`); the class is identical across the pair. This records the direct player response path only and makes no claim about the excluded piston-head provider.
