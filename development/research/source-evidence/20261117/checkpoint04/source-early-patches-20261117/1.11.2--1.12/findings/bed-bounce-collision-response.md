# Bed bounce on vertical collision
1.11.2, Ornithe Feather: `net/minecraft/block/Block.java`, `beforeCollision(World, Entity)` (624–626); `net/minecraft/entity/Entity.java`, `move(MoverType, double, double, double)` collision response (around 698–727); `net/minecraft/block/BedBlock.java` has no `beforeCollision` override.
1.12, Ornithe Feather: `net/minecraft/block/BedBlock.java`, `beforeCollision(World, Entity)` (141–150); `net/minecraft/entity/Entity.java`, same `move(...)` collision-response call (around 698–727); `net/minecraft/block/Block.java`, default `beforeCollision(...)` (643–645).
Difference: both versions call `block2.beforeCollision(world, this)` when vertical displacement is clipped (`o != y`). In 1.11.2 a bed inherits the base hook, which sets `velocityY` to zero. In 1.12 a non-sneaking entity with negative `velocityY` instead gets `velocityY = -velocityY * 0.66F`; the inherited zeroing path remains for sneaking. The extra 0.8 multiplier applies only to non-living entities.
Movement meaning: a local player landing vertically on an existing bed while not sneaking receives an upward velocity in 1.12 instead of zero vertical velocity in 1.11.2. This is a direct player collision response; it is distinct from excluded bed-entry eligibility.
