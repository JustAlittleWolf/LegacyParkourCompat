# Falling-water glass-side current suppression
1.11.2, Feather generation 2: `net/minecraft/block/LiquidBlock.java`, `isFaceSolid` (lines 83–92) and `getFlow` (131–175); `net/minecraft/block/Block.java`, `isFaceSolid` and block registration (343–345, 765, 946); `net/minecraft/block/material/Material.java`, `GLASS` and `isSolid` (24, 63–65).
1.12, Feather generation 2: `net/minecraft/block/LiquidBlock.java`, `isFaceSolid` and `getFlow` (82–99, 139–182); `net/minecraft/block/Block.java`, `isExceptionForPlacement` (219–230).
Difference: 1.11.2 delegates glass's side-face check to `Material.isSolid`, which is true for `Material.GLASS`. In 1.12, the fluid helper rejects `isExceptionForAttachment`; its placement exceptions explicitly include both `Blocks.GLASS` and `Blocks.STAINED_GLASS`. The falling branch still scans the horizontal neighbor and the block above that neighbor, but glass now returns false for both checks.
Movement meaning: For a falling water cell with no horizontal height gradient and ordinary or stained glass on one tested side, the current changes from `(0,-1,0)` to zero. The legacy player water-current path consequently loses the `-0.014` Y velocity addition for an immersed non-flying local player. Patch introduction is only bounded to after 1.11.2 and by 1.12.
