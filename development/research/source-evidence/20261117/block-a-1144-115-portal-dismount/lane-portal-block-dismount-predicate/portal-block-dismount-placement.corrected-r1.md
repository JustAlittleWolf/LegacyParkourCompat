# Portal-block dismount placement

1.14.4, Mojmap: `net/minecraft/world/entity/LivingEntity.java`, `findStandUpPosition(Entity)` lines 1664–1741 and `stopRiding()` lines 2324–2331; `net/minecraft/world/entity/player/Player.java`, `rideTick()` lines 455–459; `net/minecraft/server/level/ServerPlayer.java`, `stopRiding()` lines 763–770.
1.15, Mojmap: `net/minecraft/world/entity/LivingEntity.java`, `findStandUpPosition(Entity)` lines 1697–1792 and `stopRiding()` lines 2388–2395; `net/minecraft/world/entity/player/Player.java`, `rideTick()` lines 458–463; `net/minecraft/server/level/ServerPlayer.java`, `stopRiding()` lines 750–757.
Difference: 1.14.4 chooses dismount placement by vehicle type and nearby standable space without checking portal state. 1.15 first checks whether the block at the vehicle's current position belongs to `BlockTags.PORTALS`; when true it sets the dismounting LivingEntity to the vehicle's x/z and `vehicle.getY(1.0) + 0.001`, regardless of portal origin. `LivingEntity.stopRiding()` invokes placement only after an actual detach and only when `!level.isClientSide`. The server-side `Player.rideTick()` can reach it through ordinary mounted sneak/shift input. After placement, `ServerPlayer.stopRiding()` sends the resulting XYZ through `ServerGamePacketListenerImpl.teleport` as an absolute `ClientboundPlayerPositionPacket`; the client applies those absolute coordinates to `LocalPlayer`, then sends `ServerboundAcceptTeleportationPacket` followed by `ServerboundMovePlayerPacket.PosRot`. A passenger-list packet's local `stopRiding()` does not itself invoke placement or write XYZ because the logical-client gate is false.
Movement meaning: server-side player dismount position can change when the vehicle occupies a portal-tagged block, even for a non-portal-origin detach, and the immediate server position correction carries that result to local-player XYZ. This is a vanilla server response followed by a server-authored client position correction; it does not establish historical physics on a logical server. Exact checked boundary is 1.14.4 without the branch versus 1.15 with it; introduction is unknown within that interval.
