## Behavior comparison

- 1.14.4 `Entity.move` calls `applySneaking` before collision (`Entity.java:446-466`); 1.15.2 calls virtual `maybeBackOffFromEdge` in the same position (`Entity.java:450-470`). The 1.14.4 helper (`Entity.java:575-620`) gates on `instanceof Player`, mover `SELF` or `PLAYER`, `onGround`, and `isSneaking()`. The 1.15.2 Entity base implementation is a no-op (`Entity.java:604-606`); the Player override (`Player.java:1002-1049`) gates on `SELF` or `PLAYER`, `onGround`, and `isStayingOnGroundSurface()`. The override is inherited by LocalPlayer. `Player.isStayingOnGroundSurface()` returns `isShiftKeyDown()` (`Player.java:294-295`). 1.14.4 `Entity.isSneaking()` reads shared flag bit 1 (`Entity.java:1812-1814`); 1.15.2 `Entity.isShiftKeyDown()` reads that same bit (`Entity.java:1783-1785`). The Player type condition is inherently true for this path, so the reachable gates agree.
- The x-only, z-only and diagonal loops match in order and arithmetic: initialize `d=vec3.x`, `e=vec3.z`, `f=0.05`; query while the component(s) are nonzero and `noCollision`; clamp `[-0.05,0.05)` to zero; otherwise reduce positive or increase negative components by `0.05`. Every candidate box is `getBoundingBox().move(dx, -maxUpStep, dz)`. Both return a vector retaining the original `vec3.y`.
- `noCollision` uses the same overload defaults (`Collections.emptySet()`), `allMatch(VoxelShape::isEmpty)`, block/entity stream concatenation, and collector bounds `floor(min - 1.0E-7) - 1` through `floor(max + 1.0E-7) + 1` on all axes. Both choose `CollisionContext.of(entity)` for this non-null `this` argument; the `empty()` branch is unreachable here. Both collectors request collision chunks without loading. 1.14.4 `LevelReader` calls `getChunk(..., statusForCollisions(), false)` and `Level.statusForCollisions()` is `FULL`; 1.15.2 `Level`'s `getChunkForCollisions` calls `getChunk(..., FULL, false)`. No reachable query difference was identified.

Step-return behavior and exhaustive collision-provider geometry remain excluded by assignment.
