## Compared evidence and results

### 1.21.2 → 1.21.3: no difference in assigned operation

`net/minecraft/world/entity/player/Player.java`, `maybeBackOffFromEdge` lines 1066–1123, is byte-identical by full-source SHA. The gate remains `!flying`, not positive Y movement, mover is SELF/PLAYER, `isStayingOnGroundSurface()` (shift held), and `isAboveGround(maxUpStep)`. It copies requested X/Z to doubles; derives signed 0.05 decrements with `Math.signum`; backs X in its own loop, then Z, then both diagonally. Each loop tests `canFallAtLeast` before decrementing; component magnitudes `<= 0.05` clamp to zero. Returns adjusted X/Z with original Y. `isAboveGround` still uses on-ground, fall distance `< maxUpStep`, and the inverse zero-offset support query.

The probe in `canFallAtLeast` remains `noCollision(this, new AABB(box.minX + xOffset, box.minY - maxUpStep - 1.0E-5F, box.minZ + zOffset, box.maxX + xOffset, box.minY, box.maxZ + zOffset))`; offsets and height retain double/float types and the epsilon remains float-suffixed. The player entity context is passed through.

`CollisionGetter.noCollision(Entity,AABB)` delegates to the boolean overload with `false`; that overload iterates block collisions (not block-and-liquid collisions), then entity collisions, and finally world-border collision for a non-null entity. This is the dry block-support probe route. `BlockCollisions` constructor retains floor bounds expanded by `1.0E-7` then one additional block on every min/max axis. It tests candidate state and shape, moves shape by integer block coordinates, and checks intersection with `Shapes.joinIsNotEmpty(shape, entityShape, AND)`. Exactly-full `Shapes.block()` uses the integer unit-cube `AABB.intersects` fast path; other shapes use the shape merger.

The same gate, ordered loops, signed steps, clamp comparisons, AABB coordinates, float epsilon and native shape-provider behavior therefore remain in force.

### Ordinary support shape route and pure merger sample

The ordinary `BlockState` collision-shape call uses its collision-shape cache for context-free access; the contextual path dispatches to the block's `getCollisionShape`. Base `BlockBehaviour.getCollisionShape` returns `Shapes.empty()` only if the block lacks collision, otherwise delegates to state shape. `SlabBlock` bottom type provides `Block.box(0,0,0,16,8,16)` (world-unit shape [0,1]×[0,.5]×[0,1]); double slab returns `Shapes.block()` ([0,1]³), and top slab uses the complementary half. No profile-specific shape rewrite occurs here.

In `BlockCollisions.computeNext`, a `Shapes.block()` provider is emitted only when the query AABB intersects the unit block cell; for a bottom slab, the non-full-shape branch translates the slab by block coordinates, requires nonempty Boolean-AND overlap with the probe AABB, then emits that translated shape. `noCollision` returns false on the first nonempty emitted block shape.

Pure merger sample: with BooleanOp.AND, `Shapes.joinIsNotEmpty` first handles empty/identical and separated bounds, then merges each axis's coordinate lists with the native `IndexMerger` and checks each merged voxel interval for both shapes being full. A probe wholly below the slab top but intersecting the slab footprint is blocked; one wholly below the slab's bottom face is not; full cube occupies the entire unit cell. This is a source-level geometric reading only, not execution or a movement trajectory claim. `BlockCollisions` and `Shapes` implementations are byte-identical across all three releases.
