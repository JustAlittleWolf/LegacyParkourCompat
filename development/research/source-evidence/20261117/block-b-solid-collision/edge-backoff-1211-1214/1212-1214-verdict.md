## Operation review

In Mojmap `net/minecraft/world/entity/player/Player.java`, `maybeBackOffFromEdge` is the override used by the `Player` superclass of `AbstractClientPlayer` and `LocalPlayer`. Its gate is exactly: not flying; requested Y is not positive (`!($$0.y > 0.0)`); mover type is `SELF` or `PLAYER`; `isStayingOnGroundSurface()`; and `isAboveGround(maxUpStep)`. The surface predicate returns `isShiftKeyDown()`. Within the gate, the code copies requested X and Z to doubles, computes signed `0.05` deltas using `Math.signum`, then tests and adjusts X, Z, and finally both components diagonally in three separate `while` loops. Each loop tests `canFallAtLeast` before decrementing; an absolute component at or below `0.05` becomes zero. The returned vector preserves requested Y. No loop order, type, gate or arithmetic difference exists on either pair edge.

`isAboveGround` returns on-ground, or requires `fallDistance < maxUpStep` and no support at the zero-offset probe of height `maxUpStep - fallDistance`. `canFallAtLeast` calls `level().noCollision(this, AABB)` with un-inset X/Z bounds `[box.minX + xOffset, box.maxX + xOffset]` and `[box.minZ + zOffset, box.maxZ + zOffset]`; its vertical bounds are `box.minY - maxUpStep - 1.0E-5F` through `box.minY`. The epsilon remains float-suffixed and the height argument remains float. The entity is passed as collision context.

In `CollisionGetter.noCollision(Entity, AABB)`, the default overload selects `noCollision(entity, box, false)`. That path queries block collisions without liquids, then entity collisions, then the world border for a non-null entity; a reported collision makes the support query false. `BlockCollisions` uses the player collision context, expands cursor bounds by `1.0E-7` plus one block, and checks candidate state shapes. For a provider returning the canonical `Shapes.block()`, it uses intersection with the unit block cell. For another nonempty shape, it translates by the block position and uses `Shapes.joinIsNotEmpty(..., BooleanOp.AND)` against the probe AABB. `SlabBlock` supplies a bottom half-box `[0,1] × [0,0.5] × [0,1]`; its double type supplies `Shapes.block()`. `Shapes.joinIsNotEmpty` for AND checks merged voxel intervals for both shapes occupied, so a probe overlapping the slab volume is blocked, while a probe wholly below its lower face has no volumetric intersection. This is source-level geometry, not a simulated movement result.

The relevant base `BlockBehaviour.getCollisionShape(BlockState, BlockGetter, BlockPos, CollisionContext)` body is identical in all three releases (`hasCollision ? state.getShape(...) : Shapes.empty()`). Context-free state collision-shape access uses the state cache when available; its contextual overload dispatches to the block. This confirms the ordinary routes considered here without asserting general behavior for every provider, state-dependent resource or loaded-region case.
