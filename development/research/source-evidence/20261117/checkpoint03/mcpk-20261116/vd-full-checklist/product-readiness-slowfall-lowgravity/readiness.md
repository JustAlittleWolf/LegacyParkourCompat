# Product correspondence: Slow Falling gravity formula

Disposition: **covered at 1.20.5/1.20.6; later native-fallback correspondence is supported only for source-checked endpoints, with exact intermediate/alias endpoints pending. No conditional code gap is identified in checked product mappings.** This is a read-only product correspondence check, not source re-audit, implementation, or runtime parity verification.

## Bound evidence

- Accepted source packet `slow-falling-postintro-boundary/terminal-packet.md`, SHA-256 `F4BCF864C6E5DE492FB35904F097BC4D6F0CA304D7A4A4677C22302672B56BB8` (rehashed in product checkout).

- Accepted formula cutover: through 1.20.4 the Slow Falling branch uses a fixed 0.01 cap over gravity 0.08; from 1.20.5 it uses `Math.min(getGravity(), 0.01)` when Slow Falling is active and sampled Y velocity is nonpositive. A player gravity value of 0.005 is reachable with vanilla commands in 1.20.5+, but is not produced by ordinary movement/effect inputs alone. Runtime trajectory parity remains unverified.

## Product mapping

- `ParkourVersion.V1_20_2` aliases 1.20.2–1.20.4, `V1_20_5` aliases 1.20.5–1.20.6, `V1_21` aliases 1.21–1.21.1, and later profiles have distinct ordered constants (`src/main/java/me/wolfii/legacyparkourcompat/api/ParkourVersion.java:91-103`).
- `SlowFallingGravitySamplingHook` is the separately resolved ordinary-air-travel operation (`src/main/java/me/wolfii/legacyparkourcompat/mechanic/hook/player/SlowFallingGravitySamplingHook.java:20-26`). `ChangeResolver` chooses the closest registered emulation version at or after the selected profile (`src/main/java/me/wolfii/legacyparkourcompat/impl/ChangeResolver.java:21-32`).
- For selected 1.20.5/1.20.6 and 1.21/1.21.1, the `V1_21` `SlowFallingGravitySampling` provider is the closest applicable implementation. It returns `Math.min(baseGravity, 0.01)` on the captured Slow Falling + Y `<= 0.0` gate and otherwise returns the captured base gravity (`src/client/java/me/wolfii/legacyparkourcompat/change/v1_21/SlowFallingGravitySampling.java:25-33`). The mixin captures `entity.getGravity()`, effect presence, and Y before the air movement helper, then substitutes the hook result at native effective-gravity sampling (`src/client/java/me/wolfii/legacyparkourcompat/mixin/LivingEntityMixin.java:276-312`). At base gravity 0.005 this returns 0.005, matching the accepted 1.20.5+ expression.
- For selected 1.20.4 and earlier, the `V1_20_2` gravity-sampling fence resolves. Although its cap code is also expressed as `Math.min(baseGravity, 0.01)`, `AttributeGravity` for these profiles makes `getGravity()` return 0.08 (or zero for NoGravity), so the reachable sampled value is 0.08 and the Slow Falling result is 0.01 (`src/client/java/me/wolfii/legacyparkourcompat/change/v1_20_2/SlowFallingGravitySamplingFence.java:24-31`; `src/client/java/me/wolfii/legacyparkourcompat/change/v1_20_2/AttributeGravity.java:44-51`; `src/client/java/me/wolfii/legacyparkourcompat/mixin/EntityMixin.java:733-738`). Thus a current client's 0.005 attribute does not leak into the pre-1.20.5 formula; the old profile still produces 0.01.
- For selected 1.21.2 and later, neither sampling implementation applies: the V1_21 provider is older than the selected profile, so this operation uses native `getEffectiveGravity()` (`LivingEntityMixin.java:298-312`). The accepted source packet verifies the same `Math.min(getGravity(), 0.01)` gate at 1.21.3, 1.21.4, 1.21.11 and 26.2, which supports native fallback at those checked endpoints. Exact source for 1.21.2 was unavailable; because `V1_21_2` aliases both 1.21.2 and 1.21.3, 1.21.2 remains pending. Likewise, source packet endpoints do not verify every later alias (including 1.21.5–1.21.10 or 26.1); those exact native-fallback profile endpoints remain pending absent source evidence. The 1.21.2 alias is distinct from V1_21 (`ParkourVersion.java:96-98`).
- The cited sampling hook covers ordinary dry-air travel. Fluid and fall-flying movement route through separate operations; they were not independently audited in this correspondence. No tests, builds, or runtime launches were performed.

## Result

For the accepted conditional consequence, selected 1.20.5/1.20.6 restore the historical formula through the V1_21 provider, including reachable sub-0.01 gravity; 1.21/1.21.1 resolve the same provider. Selected 1.20.4 and earlier keep the fixed historical base gravity and therefore return 0.01. From 1.21.2 onward the product uses native fallback, matching the accepted formula at source-checked endpoints, but the exact 1.21.2, intermediate later aliases, and 26.1 endpoints remain pending because the supplied packet does not verify each one. **No conditional formula gap identified in checked mappings; exact unverified endpoints pending.** This does not establish full movement parity or runtime trajectory equality.
