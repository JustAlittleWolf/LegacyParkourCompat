# Farmland fall reversion lifts intersecting entities
1.10.2, Ornithe Feather: `decompiled_minecraft/1.10.2/ornithe-feather/net/minecraft/block/FarmlandBlock.java`, `onFallenOn`, lines 60–70; `decompiled_minecraft/1.10.2/ornithe-feather/net/minecraft/entity/Entity.java`, landing dispatch lines 810–816 and step dispatch line 673.
1.11, Ornithe Feather: `decompiled_minecraft/1.11/ornithe-feather/net/minecraft/block/FarmlandBlock.java`, `onFallenOn` and `setDirt`, lines 58–78; `decompiled_minecraft/1.11/ornithe-feather/net/minecraft/entity/Entity.java`, landing dispatch lines 832–838 and step dispatch line 695.
Difference: The fall trigger is unchanged: only the non-client world draws `world.random.nextFloat()` and reverts farmland when the draw is `< fallDistance - 0.5F`, the entity is `LivingEntity`, it is a `PlayerEntity` or mob griefing is enabled, and `width * width * height > 0.512F`. In 1.10.2 the callback only replaces farmland with dirt. In 1.11 it calls `setDirt`, which first replaces the block, obtains the dirt collision box moved to the block position, then calls `setPosition(entity.x, box.maxY, entity.z)` for every entity returned by `world.getEntities(null, box)`. Thus an intersecting player entity is snapped vertically to the dirt box top while retaining X/Z; this is not filtered to the falling entity or to players. The enclosing non-client gate makes that direct call server-authoritative. The callback does not directly invoke the local client player: any local-client position change is downstream synchronization of the server entity state. Entity landing and step callbacks are separate, unchanged dispatches; `onFallenOn` is called for positive fall distance and the farmland override delegates to `super` afterward, while `onSteppedOn` is the ordinary ground-contact path. No farmland-specific step response was found in either version.
Movement meaning: When a qualifying living player lands hard enough on farmland, 1.11's server-side dirt reversion lifts every entity intersecting the full dirt collision box to its top; 1.10.2 has no such reversion-time entity repositioning. This is a direct player movement response gated by the server-side farmland fall callback, with client state following the server update.
