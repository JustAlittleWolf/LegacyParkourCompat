# Local player shift-to-dismount on boats
1.15.2, Mojmap: `net/minecraft/world/entity/player/Player.java`, `rideTick()`, lines 459–463, dismounts when the passenger shift gate is true, but only inside `!level.isClientSide`; the branch calls `stopRiding()` and `setShiftKeyDown(false)`. `wantsToStopRiding()` at lines 290–292 returns the shift state. `LocalPlayer.rideTick()` delegates to `super.rideTick()` at lines 825–831.
1.16.0, Mojmap: `net/minecraft/world/entity/player/Player.java`, `rideTick()`, lines 452–456, applies the same passenger and shift gate without the `!level.isClientSide` condition; it calls `stopRiding()` and `setShiftKeyDown(false)`. `wantsToStopRiding()` at lines 283–285 still returns the shift state. `LocalPlayer.rideTick()` delegates to the player gate at lines 862–868.
Difference: holding shift while the local player is a passenger triggers `stopRiding()` locally in 1.16.0, while 1.15.2 performs this dismount branch only on the server. In both versions, `setShiftKeyDown(false)` writes the entity's shared flag; `LocalPlayer.isShiftKeyDown()` reads the input-backed `input.shiftKeyDown` value, so the setter does not itself clear local input state. The gate remains unchanged in 1.16.1 and 1.16.2. This is a local player ride-state response, not boat steering or vehicle motion. Ordinary crouch-input slowdown and boat-control booleans are separate.
