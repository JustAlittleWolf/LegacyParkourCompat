# Independent review: slab 1.13.0 collector candidate

## Verdict

**ACCEPT** for the bounded collector operation and the explicit proof-gated adapter contract in neutral candidate commit `a7838321aefc85814153bd8431eda336d59d4fe1` (`feat/slab-113-collector-bundle`). No key source-fidelity or representability defect found.

## Review findings

- **Scan bounds and traversal:** `BlockCollisionCollection.java:60-65, 69-80` computes the 1.13.0 padded integer interval using floor(min)-1 / ceil(max)+1, with exclusive maxima. `MathHelper.floor/ceil` in 1.13.0 and current `Mth.floor/ceil` use corresponding double semantics for this conversion. The nested X, Z, Y traversal and the per-X, per-X/Z, and whole-region partial accumulators match `WorldView.getBlockCollisions` (`:69-80, 113-118`; source `WorldView.java:113-175`).
- **Corner/perimeter/chunk behavior:** `:72-83` skips the four X/Z corner columns before the y=64 chunk probe, and skips the top Y cell on non-corner perimeter columns. This matches the outer corner exclusion, `isChunkLoaded((x,64,z))`, and inner `if (!bl3 && !bl4 || q != l - 1)` source gate (`1.13 WorldView.java:124-142`). The repeated corner check in the Y loop is redundant but has no semantic effect.
- **Provider and overlap gates:** each loaded candidate position gets one provider result; missing results and missing required state/shape values fail loudly. Per-cell state/provider equivalence is checked before shape processing (`:84-97`). Partial shapes are translated, excluded by `exclusion AND shape`, and retained only by `bounds AND shape` (`:108-114`), corresponding to the historical `overlap` gates (`1.13 WorldView.java:155-165`). Current `Shapes.joinIsNotEmpty` uses the same AABB rejection threshold and coordinate-merger / voxel predicate structure as historical `VoxelShapes.overlap` for these AND checks (`1.13 VoxelShapes.java:159-200`; `26.2 Shapes.java:175-232`). The external equivalence flags remain necessary to attest equal bounds, exclusion, provider state/results, and shape aggregation; they are documented in the hook and candidate report.
- **Raw full-shape identity and accumulator tail:** the old identity classification is carried explicitly as `CollisionCell.canonicalFullShape`, not derived from `isFullBlock` or geometry (`BlockCollisionCollectionHook.java:47-56`). A claimed canonical-full cell whose current local shape is not the 26.2 canonical block shape triggers native fallback (`BlockCollisionCollection.java:93-97`). Canonical-full cells enter the separate full-cell tail before partial overlap filtering (`:102-105`), matching the historical `BitSetVoxelSet` path, which adds full cells without the partial-shape exclusion/bounds gates (`1.13 WorldView.java:145-154`). Partials reproduce the nested grouping, optimize once, then join the full-cell result (`:108-129`). Folding translated unit cubes cannot independently establish identical legacy integer-grid internals, but `shapeAggregationEquivalent` explicitly carries that proof obligation and must stay false when representation or construction parity is unknown.
- **Fallback coverage:** false query equivalence/participation proofs, step-up, border checks, only-first queries, empty bounds, and non-finite bounds return `Optional.empty()` before reconstructing a shape (`:40-58`). A false per-cell equivalence or incompatible canonical-full representation also falls back. Empty means native fallback by hook contract (`BlockCollisionCollectionHook.java:12-19`). The proof booleans are attestations by the adapter, not independently verified facts; this is clearly assigned to the adapter contract and is not presented as an intrinsic parity guarantee.
- **Resolver fences:** closest-later resolution picks the 1.12 native fence for V1_12 and earlier, the V1_13 collector for V1_13, and the V1_13_1 native barrier for V1_13_1 and later (`ChangeResolver.java:21-34`; annotations in the three implementations). That matches the source-supported 1.13.0 aggregate collector versus 1.13.1/.2 ordered stream distinction and the narrowly bounded 26.2/1.13.1/.2 native witness result. The barrier makes no broader equivalence claim.
- **Scope:** the candidate adds one collector hook and does not add an axis hook or duplicate axis implementation. The collector is generic over positions/shapes and has no slab coordinates, threshold witness value, or witness-only branch. Witness-only evidence remains documentation in the findings.
- **Source comments:** the collector Javadoc names the exact release, mapping, classes, and members used for historical and current behavior. It appropriately omits source hashes from Java comments; source integrity is bound separately by accepted manifests and this review's hash manifest.

## Limits

This accepts the candidate's collector implementation only under its explicit adapter attestations. It does not certify any adapter as capable of proving those flags at runtime, broad 26.2-to-1.13 provider equivalence, axis clipping, or full movement parity. No build, tests, runtime, or game execution was performed.

## Disposition

No correction requested.
