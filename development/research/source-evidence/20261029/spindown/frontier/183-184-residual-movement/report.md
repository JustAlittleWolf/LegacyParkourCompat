The code path is established, but this client-only assignment does not decide whether server-authoritative dimension transfer belongs in this movement scope or whether a client change is appropriate.

This is not a full-pair freeze, source acceptance, exact patch-boundary, runtime-parity, or implementation-readiness claim. Intermediate releases, runtime effects, and the indirect vine-presence dependency remain unreviewed.
