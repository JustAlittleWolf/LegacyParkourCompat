## Source-traced claims

**Entity-motion packet:** Both packet bodies read and write an entity ID followed by three signed shorts in x/y/z order, then dispatch `handle` to `ClientGamePacketListener.handleSetEntityMotion`. In 1.20.6, `getXa/getYa/getZa` return the stored ints and the implementation in `ClientPacketListener.handleSetEntityMotion` divides each by `8000.0` at the call site. In 1.21.1 the accessors each perform that same integer-to-double division and the handler passes the results through. Thus, for the same decoded integer triplet, each path supplies the same three double values to `Entity.lerpMotion`. Both handlers call `PacketUtils.ensureRunningOnSameThread`, resolve by entity ID, and leave velocity untouched when lookup returns null. There is no local-player-only branch. `Entity.lerpMotion` calls `setDeltaMovement(x,y,z)` in both versions, and that overload replaces the complete vector via a new `Vec3`; this path does not add to the prior vector.

**Explosion packet:** The packet source is byte-for-byte hash-identical, including its float knockback getters and `handleExplosion` dispatch. In each listener implementation, `handleExplosion` enforces main-thread execution, constructs the explosion from packet fields, calls `finalizeExplosion(true)`, then adds the three received knockback floats to the local player's current delta vector and assigns that result. This is addition after finalization, unlike the entity-motion replacement path.

**Immediate local-player tick consumer:** `LocalPlayer.tick` in both releases gates `super.tick()` on `level().hasChunkAt(getBlockX(), getBlockZ())`. The `LivingEntity.tick` chain calls virtual `aiStep()` while the entity is not removed. `LocalPlayer.aiStep` reaches the inherited chain through `Player.aiStep` and `LivingEntity.aiStep`. At the cited `LivingEntity.aiStep` stage, both releases first apply the same conditional `0.98` delta scaling when `!isEffectiveAi()` (after the same interpolation branch), then read the vector and zero x, y, and z independently when the component's absolute value is strictly less than `0.003`, write the resulting vector, and later call `travel` in the same method. The audited threshold, strict comparisons, component order, cleaned vector setter, and travel call point match. The same state gates qualify the comparison. This establishes only the immediate consumer sequence; later travel branches and complete tick behavior are outside this audit.

## Result and limits

**Accept** the report's bounded packet decode/response and immediate consumer claims against the canonical source bodies and selected parent-manifest entries. The representation change moves entity-motion scaling from listener to accessors without changing the result for equal decoded integer inputs. Explosion addition and entity-motion replacement remain distinct operations. Raw artifact inputs were not recomputed, so source identity is supported by the exact ready/source manifest binding and selected source hashes, not by revalidating the original client/mapping archives. No pair-wide completeness, source freeze, runtime equivalence, or trajectory conclusion follows.
