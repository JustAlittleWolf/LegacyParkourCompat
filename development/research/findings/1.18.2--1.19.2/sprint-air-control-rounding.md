# ascending crouch movement bypasses edge restraint in 1.19.2

1.18.2, mojmap: `1.18.2/mojmap/net/minecraft/world/entity/Entity.java`, move 543-563.
1.19.2, mojmap: `1.19.2/mojmap/net/minecraft/world/entity/Entity.java`, move 547-567.
1.18.2, mojmap: `1.18.2/mojmap/net/minecraft/client/player/LocalPlayer.java`, move 889-894.
1.19.2, mojmap: `1.19.2/mojmap/net/minecraft/client/player/LocalPlayer.java`, move 979-984.
1.18.2, mojmap: `1.18.2/mojmap/net/minecraft/world/entity/player/Player.java`, isStayingOnGroundSurface 303-305; maybeBackOffFromEdge 1032-1081; isAboveGround 1082-1085.
1.19.2, mojmap: `1.19.2/mojmap/net/minecraft/world/entity/player/Player.java`, isStayingOnGroundSurface 312-314; maybeBackOffFromEdge 1061-1114; isAboveGround 1115-1118.

Difference: Both versions dispatch local `LocalPlayer.move()` through `super.move()` to `Entity.move()`, which calls the virtual `maybeBackOffFromEdge()` before `collide()`. In 1.18.2, a non-flying `SELF` or `PLAYER` move is restrained when `isStayingOnGroundSurface()` and `isAboveGround()` hold; the predicate is shift-key-down, and there is no requested-Y condition. The same 0.05-step X/Z backoff loops preserve the original Y component. 1.19.2 adds `requestedDelta.y <= 0.0` to that guard. Its X/Z backoff loops are otherwise unchanged.

Movement meaning: Local player movement -> `LocalPlayer.move()` -> `Entity.move()` -> virtual `Player.maybeBackOffFromEdge()` -> `collide()`. Under the shared preconditions (not flying, mover type SELF/PLAYER, shift key held, above-ground probe true), 1.19.2 skips the edge probe loops when requested Y is positive; 1.18.2 still probes and shortens X/Z until the shifted bounding box has support or the horizontal request is reduced to zero. `isAboveGround()` uses the same `onGround`, `fallDistance`, `maxUpStep` and `CollisionGetter.noCollision()` query at both endpoints; the full collision query file is byte-identical. The world shapes and entity collisions that satisfy these queries are scene inputs, not additional changed code dependencies for the guard delta. Source-proven: the vector passed to collision resolution can retain more of its requested horizontal component in 1.19.2 for positive-Y movement under the stated guards. Predicted consequence: the player can move farther horizontally while rising over a supported-edge boundary in 1.19.2. The actual resolved position depends on the collision shapes and was not simulated. This comparison identifies a change within the endpoints; it does not establish the first release where it appeared. Artifact revision `feather-r1-2026-10-07` does not apply: the finding uses the reverified Mojmap endpoints, while the revision concerns Feather-derived artifacts for 1.8.9-1.13.2.
