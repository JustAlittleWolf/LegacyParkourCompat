# Carpet collision shape becomes one-sixteenth high
1.7.10, Ornithe Feather: `net/minecraft/block/Block.java` registers carpet at ID 171 (line 662). `net/minecraft/block/CarpetBlock.java`, `getCollisionShape(World,int,int,int)`, lines 29–33, returns a box with `minY=maxY=y`. `net/minecraft/util/math/Box.java`, `intersects`, lines 172–177, can collect this zero-height box when its Y plane is strictly inside the query interval.
1.8, Ornithe Feather: `net/minecraft/block/Block.java` registers carpet at ID 171 (line 1089). `CarpetBlock.java` keeps stored bounds through line 26 and declares no collision override; it inherits `Block.getCollisionShape(World,BlockPos,BlockState)`, lines 299–303, which returns a box from `y` through `y+0.0625F`.
Difference: The old zero-height carpet plane can be collected and clips downward movement when the query crosses its Y. A descending player whose feet start above the plane is stopped at Y=`y`; the new one-sixteenth-high carpet stops the same player at Y=`y+0.0625F`.
Movement meaning: Put carpet at `(0,1,0)` on a full support block at `(0,0,0)`. Start a non-noClip ordinary player centered over the carpet with AABB bottom Y=1.125 and X/Z intervals `[0.2,0.8]`; request `move(0,-0.2,0)`. The swept query spans Y=0.925 to the player's top, so it intersects the support and crosses the carpet plane at Y=1. In 1.7.10 the support and carpet plane clip downward movement to `-0.125`, leaving AABB bottom Y=1. In 1.8 the support allows `-0.125`, then the carpet top clips the same request to `-0.0625`, leaving bottom Y=1.0625. With no horizontal movement, the step gate is false. This is a source-derived reachable falling-player path; no runtime trajectory was run.
