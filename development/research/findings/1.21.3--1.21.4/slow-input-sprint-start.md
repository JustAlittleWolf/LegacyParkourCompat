# Slow input can start sprinting with high sneaking speed in 1.21.3

1.21.4, Mojmap: `net/minecraft/client/player/LocalPlayer.java`, `isMovingSlowly` lines 602–604, input scaling and sprint checks in `aiStep` lines 662–710, `canStartSprinting` and impulse threshold lines 1053–1071; `net/minecraft/world/entity/ai/attributes/Attributes.java`, `SNEAKING_SPEED` lines 75–77; `net/minecraft/server/commands/AttributeCommand.java`, base-value setting lines 300–302; `net/minecraft/client/multiplayer/ClientPacketListener.java`, attribute update lines 2168–2183; `net/minecraft/world/item/enchantment/Enchantments.java`, Swift Sneak modifier lines 570–577.
Difference: In both releases, crouching or visually crawling scales forward input by `SNEAKING_SPEED` before sprint-start checks; the dry-land threshold is `forwardImpulse >= 0.8`. In 1.21.3, `canStartSprinting` has no slow-state gate. In 1.21.4 it adds `(!isMovingSlowly() || isUnderWater())`. `SNEAKING_SPEED` is a synced vanilla attribute with range 0–1, and vanilla command/server attribute updates reach the local player's attribute instance. Thus a dry crouching/crawling player with server-supplied `SNEAKING_SPEED >= 0.8` can pass the 1.21.3 threshold and start sprinting when other gates pass, but the same slow state is rejected in 1.21.4. Ordinary survival equipment does not reach this threshold: Swift Sneak III raises the default 0.3 only to 0.75. Underwater starts retain the 1.21.4 exception. The exact patch boundary within 1.21.3–1.21.4 is unknown.
Movement meaning: With a synced `SNEAKING_SPEED` value of at least 0.8 and the other sprint conditions satisfied, dry slow input can start sprint movement in 1.21.3; 1.21.4 prevents that sprint-state transition. This applies to the vanilla command/server-provided attribute state, not ordinary survival gear alone. The stable cutover is 1.21.4: the gate is absent in 1.21.3 and present in 1.21.4.
