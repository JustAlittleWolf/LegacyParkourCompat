# Scaled Shulker peek push query geometry

1.21.3, Mojmap: `net/minecraft/world/entity/monster/Shulker.java`, `updatePeekAmount()` and `onPeekAmountChange()` (210–244), `getProgressDeltaAabb(float, Direction, float, float)` (250–256); `net/minecraft/world/level/Level.java`, `getEntities(Entity, AABB, Predicate)` (648–664); `net/minecraft/client/player/LocalPlayer.java`, `move(MoverType, Vec3)` (873–879); `net/minecraft/client/multiplayer/ClientPacketListener.java`, local-player registration (442).
1.21.4, Mojmap: `net/minecraft/world/entity/monster/Shulker.java`, `updatePeekAmount()` and `onPeekAmountChange()` (209–243), `getProgressDeltaAabb(float, Direction, float, float, Vec3)` (249–256); `net/minecraft/world/level/Level.java`, `getEntities(Entity, AABB, Predicate)` (649–664); `net/minecraft/client/player/LocalPlayer.java`, `move(MoverType, Vec3)` (903–911); `net/minecraft/client/multiplayer/ClientPacketListener.java`, local-player registration (443).

Difference: Both releases convert the synchronized raw peek amount with `* 0.01F`, advance the current amount by `0.05F`, and compute physical peek as `0.5F - sin((0.5F + peek) * PI) * 0.5F`. The push delta is `(physicalNow - physicalBefore) * getScale()` and pushes only when `!(delta <= 0.0F)`. Both query with `NO_SPECTATORS` and exclude passengers of the same vehicle, then skip Shulkers and `noPhysics` entities before calling `move` with the direction-scaled delta. The query geometry differs: 1.21.3 builds `(0,0,0)..(scale,scale,scale)` and shifts it by `(x - 0.5, y, z - 0.5)`; 1.21.4 builds `(-scale/2,0,-scale/2)..(scale/2,scale,scale/2)` and moves it to the Shulker position. At non-default scale, these boxes can admit different player bounding boxes. The client tick path runs the same peek update, and the local player is registered in the queried level; `Level.getEntities` filters the Shulker argument and supplied predicate, not the local player. Thus a local player can receive this direct displacement when it passes the selector and `noPhysics` gate.

Applicability evidence: 1.20.4, Mojmap `Shulker.java`, `onPeekAmountChange()` (226–244), computes an unscaled peek delta. 1.20.6, Mojmap `Shulker.java`, `onPeekAmountChange()` (225–243), multiplies that delta by `getScale()`; 1.21.1 and 1.21.3 retain that scaled push (225–243 and 226–244 respectively). Scale-based peek pushing begins in 1.20.5; earlier representatives retain the native scaled feature response.

Movement meaning: For scale-based peek pushes, the horizontal query geometry changed between 1.21.3 and 1.21.4, so an expanding client Shulker can directly displace a local player in one release and not the other when the player box intersects only one swept query box. Any legacy local-player admission must retain the positive-delta condition, spectator and same-vehicle exclusions, and `noPhysics` skip. This finding covers direct peek displacement only; `makeBoundingBox()` also changed, so it does not claim complete Shulker parity.
