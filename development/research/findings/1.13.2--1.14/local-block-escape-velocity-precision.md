# Local block escape velocity precision

1.13.2, ornithe-feather (`feather-gen2:1.13.2+build.2`): `1.13.2/ornithe-feather/net/minecraft/client/entity/living/player/LocalClientPlayerEntity.java`, `pushAwayFrom`, lines 401–451; `mobTick`, lines 718–721, 837. `1.13.2/ornithe-feather/net/minecraft/entity/Entity.java`, double velocity fields, lines 115–117.
1.14, ornithe-feather (`feather-gen2:1.14+build.2`): `1.14/ornithe-feather/net/minecraft/client/entity/living/player/LocalClientPlayerEntity.java`, `pushAwayFrom`, lines 389–433; `mobTick`, lines 646–651, 774. `1.14/ornithe-feather/net/minecraft/entity/Entity.java`, `m_94091929`, `m_28162558`, `m_32166403`, lines 2585–2595; `1.14/ornithe-feather/net/minecraft/util/math/Vec3d.java`, constructor, lines 11–15.

Difference: When a local player's block escape probe selects west/east/north/south, 1.13.2 assigns the selected double velocity component from the float literal `-0.1F` or `0.1F`, producing magnitude `0.10000000149011612`. 1.14 passes the double literal `-0.1` or `0.1` to the vector velocity setter. That setter constructs a vector from the supplied doubles and directly replaces the velocity field. The other horizontal component and Y are copied unchanged. West/north remain negative and east/south positive; a failed selection performs no write. The two adjacent stable releases establish 1.14 as the first stable precision change.

Movement meaning: Four local-player probes run before the parent living movement step. When an admitted probe selects the same direction in both versions, the assigned horizontal speed differs by approximately `1.49e-9` before subsequent movement operations. Multiple probes may overwrite the same component in their existing call order. The old method rejects noClip internally and the new caller guards all four probes with `!noClip`; these call-boundary guards are equivalent. Escape occupancy predicates and probe sample coordinates are separate dependencies; this finding establishes the precision of the response once a direction is selected.
