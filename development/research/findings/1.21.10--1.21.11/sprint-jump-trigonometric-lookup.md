# Sprint-jump trigonometric lookup precision

1.21.10, Mojmap: `net/minecraft/world/entity/LivingEntity.java`, `LivingEntity.jumpFromGround`, lines 2235–2247; `net/minecraft/util/Mth.java`, float table initialization lines 31–35 and `Mth.sin(float)` / `Mth.cos(float)` lines 48–53. `jumpFromGround` multiplies the float yaw by `(float) (Math.PI / 180.0)` and passes the resulting float angle to float overloads. Those overloads multiply by `10430.378F` (adding `16384.0F` for cosine), truncate to an `int`, mask with `65535`, and index the float `SIN` table.

1.21.11, Mojmap: `net/minecraft/world/entity/LivingEntity.java`, `LivingEntity.jumpFromGround`, lines 2269–2281; `net/minecraft/util/Mth.java`, float table initialization lines 34–38 and `Mth.sin(double)` / `Mth.cos(double)` lines 50–56. The yaw conversion still produces a float angle, which Java widens when passed to the new double overloads. The overloads multiply by `10430.378350470453` in double precision (adding `16384.0` for cosine), convert through `long`, mask with `65535L`, and index `SIN`. `Mth` initializes its float table using `(float) Math.sin(index / 10430.378350470453)` instead of `(float) Math.sin(index * Math.PI * 2.0 / 65536.0)`.

Difference: the jump's yaw conversion and float angle are unchanged, but the table-index calculation changes from float arithmetic with `int` truncation to double arithmetic with `long` truncation. The trigonometric lookup and table initialization are one operation boundary, separate from the impulse-multiplier precision boundary recorded in `finding-sprint-jump-scalar.md`. The selected 26.2 sources retain the 1.21.11 double lookup path.

Movement meaning: an ordinary sprinting player jump uses these lookups after setting vertical velocity. At yaw −45°, the old float products before truncation are −8192/8192 (sine/cosine), while the new double products are −8192.000227963168/8191.999772036832. Sine index stays 57344, while cosine changes from 8192 to 8191; the cosine table value changes from 0.70710677 to 0.707039. At yaw −175.979° stored as a float, the old products are −32035.998/−15651.998 and the new products are −32036.000079449317/−15652.000079449317. The old lookup selects sine/cosine indices 33501/49885, while the new lookup selects 33500/49884. The table values change from −0.07021766/−0.9975317 to −0.070122026/−0.99753845. These lookup differences change the horizontal sprint impulse while preserving the same float yaw conversion.
