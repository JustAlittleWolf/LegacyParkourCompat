# Relative movement trigonometric lookup precision
1.21.10, Mojang official mappings: net/minecraft/util/Mth.java, table initializer lines 32-36 and sin/cos lines 48-54; net/minecraft/world/entity/Entity.java, getInputVector lines 1595-1604.
1.21.11, Mojang official mappings: net/minecraft/util/Mth.java, table initializer lines 33-37 and sin/cos lines 50-56; net/minecraft/world/entity/Entity.java, getInputVector lines 1613-1622.
Difference: the old table is generated with (float)Math.sin(index * Math.PI * 2.0 / 65536.0), and old sin/cos accept float radians, multiply by 10430.378F, add 16384.0F for cosine, truncate to int and mask with 65535. New generation uses (float)Math.sin(index / 10430.378350470453); new sin/cos accept double radians, multiply by that double scale, add 16384.0 for cosine, truncate to long, mask with 65535L, and cast to int. Both input callers still multiply float yaw by the float constant (float)(Math.PI / 180.0); the new invocation widens those float radians to double.
Movement meaning: ordinary forward input at yaw -45F computes the same float radians -0.7853981852531433, but old cosine selects table index 8192 while new cosine selects 8191. Sine selects index 57344 in both. Cosine values are approximately 0.7071067690849304 and 0.7070389986038208, changing the Z acceleration of nonzero forward input. Table generation's expression rewrite is evidence; no separate observable difference is claimed solely from that rewrite. This is a static arithmetic consequence, not gameplay parity validation.
Boundary: these adjacent stable releases establish stable 1.21.11 as the first release with the new expressions. Snapshot introduction remains unknown. Inspected exact 26.1 and 26.2 sources retain them.
