# Nether-lava current contribution cutoff and depth

1.21.11, Mojmap: `net/minecraft/world/entity/Entity.java`, `updateInWaterStateAndDoFluidPushing` and `updateFluidHeightAndDoFluidPushing` (1501–1507, 3509–3573); `net/minecraft/world/entity/player/Player.java`, `isPushedByFluid` (1679–1681); `net/minecraft/world/phys/AABB.java`, `deflate` and `inflate` (183–190, 280–285); `net/minecraft/data/worldgen/DimensionTypes.java` (78–83).
26.1.2, unobfuscated: `net/minecraft/world/entity/Entity.java`, `updateFluidInteraction` and `getFluidInteractionBox` (1558–1581, 4015–4023); `net/minecraft/world/entity/EntityFluidInteraction.java`, `update` and `Tracker.applyCurrentTo` (32–89, 171–188); `net/minecraft/world/entity/player/Player.java`, `isPushedByFluid` (1673–1675); `net/minecraft/data/worldgen/DimensionTypes.java` (88–93).
Difference: Both endpoints use the same Nether lava-current scale, 0.007, and only push a player when `isPushedByFluid()` (`!abilities.flying`) is true. Both standalone-player scans deflate the bounding box by 0.001 and admit cells whose fluid top reaches the scan minimum. The old code measures depth from the deflated scan minimum (actual minY + 0.001); the new tracker measures from actual minY, so each admitted shallow cell has a depth contribution larger by 0.001. The old code applies any nonzero summed current, averages player samples, scales it, then raises a small impulse to 0.0045 when horizontal velocity is below 0.003. The new tracker requires a nonzero count and accumulated `lengthSqr() >= 1.0E-5F` before averaging, Nether scaling, or minimum-impulse handling.
Movement meaning: For a non-flying, nearly stationary player in Nether lava, a weak but nonzero current below the new squared-length cutoff no longer produces the old 0.0045 minimum impulse. For currents that pass the cutoff, admitted shallow cells use the depth measured from actual minY. This finding covers the 1.21.11-to-26.1.2 current-contribution operation; the newly introduced post-move lava-current application is a separate timing change.
