# Border collision query drops the exterior shape at integer-boundary epsilon
1.15.2, mojmap: `1.15.2/mojmap/net/minecraft/world/level/border/WorldBorder.java`, `StaticBorderExtent.updateBox`, lines 404–420, and `1.15.2/mojmap/net/minecraft/world/level/CollisionGetter.java`, `noCollision` and `getBlockCollisions`, lines 51–90.
1.16, 1.16.1, 1.16.2, 1.16.3, 1.16.4, and 1.16.5, mojmap: each release's `mojmap/net/minecraft/world/level/CollisionSpliterator.java`, constructor lines 33–53 and `worldBorderCheck`/helpers lines 102–131. 1.16.5, mojmap: `1.16.5/mojmap/net/minecraft/world/level/border/WorldBorder.java`, `MovingBorderExtent.getCollisionShape`, lines 324–337, and `Player.java`, `maybeBackOffFromEdge`, lines 1008–1039.

Difference: `WorldBorder.getCollisionShape()` is `Shapes.INFINITY` minus the box between the floored minima and ceiled maxima, so it represents the border exterior. For an entity AABB strictly inside the integer-bounded border interior, both `entity.getBoundingBox()` and its `deflated(1.0E-7)` form remain inside that interior and do not intersect the exterior shape. If the entity box is within `1.0E-7` of an integer face, its inflated form can intersect the exterior. 1.15.2 emits the shape when the deflated box does not intersect it and the inflated box does. In each checked 1.16 release, `worldBorderCheck` instead skips both shape tests when `isBoxFullyWithinWorldBorder` finds the entity box strictly between the same floored/ceiled faces. This drops the border shape for that near-face case. The collision-query candidate AABB is separate: `noCollision(entity, candidateAABB)` passes it to the collision query, but both versions' border admission check uses `entity.getBoundingBox()`; 1.16's spliterator stores the candidate as `box` and the entity as `source`. With no other intersecting shapes, `noCollision`'s all-match reduction therefore changes from false in 1.15.2 to true in the checked 1.16 releases.

Movement meaning: Player step/edge-support probes call `noCollision` with a moved candidate AABB. Near an integer border face, the changed border-shape emission can change that probe's collision result and therefore its movement decision.
