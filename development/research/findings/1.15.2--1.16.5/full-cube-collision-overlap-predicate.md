# Full-cube collision collection uses strict box intersection
1.15.2, Mojmap: `1.15.2/mojmap/net/minecraft/world/level/CollisionGetter.java`, `getBlockCollisions`, lines 67–120; `world/phys/shapes/Shapes.java`, `joinIsNotEmpty`, lines 161–213, and `createIndexMerger`, lines 384–405; `IndirectMerger.java`, lines 12–48.
1.16.5, Mojmap: `1.16.5/mojmap/net/minecraft/world/level/CollisionGetter.java`, lines 44–68; `CollisionSpliterator.java`, `collisionCheck`, lines 60–94; `world/phys/AABB.java`, `intersects`, lines 208–210.
Difference: The old block stream intersects every translated collision shape with `Shapes.create(queryBox)` using `Shapes.joinIsNotEmpty(..., AND)`. The new extracted stream detects shape identity `voxelShape == Shapes.block()` and uses strict `queryBox.intersects(blockX, blockY, blockZ, blockX + 1, blockY + 1, blockZ + 1)` for that branch. Non-full-cube shapes still use the voxel intersection. The unchanged `IndirectMerger` merges nearby coordinates within 1e-7, whereas AABB intersection uses strictly positive overlap on all axes without that tolerance.
Movement meaning: A raw collision query box overlapping a full cube by about 5e-8 along one face, with ordinary substantial overlap on the other two axes, can previously yield no block shape and now yield the cube. `Player.maybeBackOffFromEdge` directly uses `level.noCollision` on translated, non-inset player boxes to decide support; therefore this can change its horizontal reduction at tiny edge overlaps even with the same grounded gate. It is separate from the changed airborne eligibility gate and from `canEnterPose`'s additional inset. Clipping arithmetic itself is not claimed to change. The witness uses only a full cube, no entities and a remote world border, so entity collision filters and border shortcuts do not establish the claim.
Boundary: Exact 1.16 Mojmap `CollisionSpliterator.java`, lines 60–94, already contains this strict full-cube branch; the complete file is byte-identical to 1.16.5. The release change is present in 1.16; no snapshot boundary is claimed.
