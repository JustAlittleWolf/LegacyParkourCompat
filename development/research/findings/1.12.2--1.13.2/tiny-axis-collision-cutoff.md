# Sub-epsilon grounded player motion reaches collision clipping

1.12.2, Feather Gen2 build 2: `net/minecraft/entity/Entity.java`, `move`; `net/minecraft/util/math/Box.java`, `intersectX`; `net/minecraft/entity/living/LivingEntity.java`, `mobTick` and `moveRelative`; `net/minecraft/client/entity/living/player/LocalClientPlayerEntity.java`, `mobTick` and `serverTickAi`; `net/minecraft/entity/living/player/PlayerEntity.java`, `initAttributes` and `getSpeed`.
1.13.2, Feather Gen2 build 2: `net/minecraft/entity/Entity.java`, `move`; `net/minecraft/block/shape/VoxelShapes.java`, `calculateMaxOffset`; `net/minecraft/world/WorldView.java`, movement `getCollisions`; corresponding `LivingEntity`, `LocalClientPlayerEntity` and `PlayerEntity` members.
Difference: The old AABB clipper moves a positive X request up to the remaining wall gap without an epsilon. The new voxel-shape helper returns zero for a positive remaining offset below `1e-7` when the movement query has any collision-shape candidate. A reachable local-player input can produce the needed request: player movement-speed base `0.1F` plus an equipped operation-0 `-0.09999995F` item modifier yields effective `getSpeed()` `5.2154064e-8`; after the local tick's `0.98F` forward-input damping, ordinary grounded stone acceleration yields X `5.1110973e-8` in 1.12.2 and `5.1110977e-8` in 1.13.2. With player feet at `y=1`, the float-width-derived leading face at `x=0.99999999` (actual gap `1.0000000050247593e-8`) before a full stone wall at `x=1`, 1.12.2 clips to the gap while 1.13.2 returns zero. The concrete full-stone collector path is closed for this witness; step alternatives make no greater horizontal progress and revert to the normal route.
Movement meaning: In this bounded reachable state, the old player box advances to the wall gap while the new solver leaves it stationary on X. The configured loot path and self attribute packet delivery are vanilla mechanisms; this does not assert that a built-in default loot table supplies this exact modifier. Source arithmetic establishes the witness, not runtime parity.
