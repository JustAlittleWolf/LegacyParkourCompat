# Auto-jump eligibility now checks the block jump factor
1.14.4, Mojmap: `net/minecraft/client/player/LocalPlayer.java`, `updateAutoJump`, lines 856–958.
1.15.2, Mojmap: `net/minecraft/client/player/LocalPlayer.java`, `updateAutoJump` and `canAutoJump`, lines 862–976; `net/minecraft/world/entity/Entity.java`, `getBlockJumpFactor`, lines 584–588; `net/minecraft/world/level/block/Blocks.java`, honey block properties, line 2121.
Difference: The 1.14.4 precondition checks enabled auto-jump, the timer, ground contact, sneak input, passenger state, and nonzero movement input before scanning the approach for a step. In 1.15.2 those same checks are factored into `canAutoJump`, which also requires `getBlockJumpFactor() >= 1.0`. The factor uses the block at the player's position, falling back to the block below when the first factor is 1.0; the new honey block has factor 0.5. The path is reachable with auto-jump enabled, the player grounded and moving toward a step, not shifting or mounted, and standing over a block with a sub-1.0 jump factor.
Movement meaning: In 1.14.4 the approach scan can arm `autoJumpTime` for the next tick in that state; in 1.15.2 it returns before the scan, so the automatic jump input is not produced there.
