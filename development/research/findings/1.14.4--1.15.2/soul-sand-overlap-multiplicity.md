Difference: The soul-sand collision shape is 7/8 block high throughout these representatives (1.8.9 expresses it as `1 - 0.125F`; later sources use `0.875` or `14/16`). In the checked pre-1.15 representative profiles listed above, the entity scan iterates inclusive integer block coordinates from the bounding box minimum plus `0.001` to its maximum minus `0.001`, then calls each state/block collision callback; it does not test each block's collision shape. Soul sand multiplies horizontal velocity by the double value `0.4` for every overlapped cell (the oldest source writes X and Z separately; later callbacks multiply the velocity vector). In 1.15, soul sand has no callback override; after the same cell scan, `Entity.move` multiplies X/Z by one selected block speed factor. The base selector uses the block at the entity position, or the block below its movement-affecting position when the current factor is `1.0`, with water and bubble-column exceptions. `Player.getBlockSpeedFactor` returns `1.0F` while flying or fall-flying.
