# Riptide trident durability gate

1.13–1.13.2, Ornithe Feather: `net/minecraft/item/TridentItem.java`, `startUsing(...)` lines 115–126 in 1.13.2; `stopUsing(...)` lines 56–106. The same start predicate is present in 1.13 and 1.13.1.
1.14, 1.14.1, 1.14.2, 1.14.3 and 1.14.4: Ornithe Feather/Yarn, `net/minecraft/item/TridentItem.java`, `use(...)` lines 117–129 in 1.14.3, with the same damage gate in each checked patch; Mojmap 1.14.4, `net/minecraft/world/item/TridentItem.java`, `use(...)` lines 117–129 and `releaseUsing(...)` lines 57–113.
1.15, 1.15.1 and 1.15.2, Mojmap: `net/minecraft/world/item/TridentItem.java`, `use(...)` lines 111–123 and `releaseUsing(...)` lines 51–107; all three files have identical relevant bodies.

Difference: Riptide exists by 1.13. On every checked 1.13–1.14.4 source, starting use is rejected only when current damage is at least max damage. In 1.15 and each stable patch through 1.15.2, the predicate instead rejects at max damage minus one. A Riptide trident with exactly one durability remaining can therefore start use in 1.14.4 but not in any checked 1.15 stable release. The existing water-or-rain gate and charged-release requirement (`useDuration - remainingUseTime >= 10`) otherwise remain. The client path is `Minecraft` (`useItem` at 1.14.4 line 1224 / 1.15.2 line 1263; release at lines 1431 / 1475) → `MultiPlayerGameMode.useItem` → `ItemStack.use` → `TridentItem.use`; release delegates through `MultiPlayerGameMode.releaseUsingItem` → player / `ItemStack.releaseUsing` → `TridentItem.releaseUsing` (`MultiPlayerGameMode.java` lines 301–316 and 376–379; `ItemStack.java` use lines 166 / 171 and release lines 380 / 389). On release, the Riptide branch applies a look-direction push, starts the 20-tick auto-spin attack, and, when on ground, moves the player upward by `1.1999999F`. These responses are outside the `!level.isClientSide` block containing durability damage and projectile creation, so the predicate change removes a reachable direct client-player movement response at one remaining durability. Server durability production is not part of this finding.
