# Sneak-speed scalar source

1.18.2, Mojmap: `net/minecraft/client/player/LocalPlayer.java:601-602` defines `isMovingSlowly()`; its `aiStep` (`LocalPlayer.java:656`) passes that boolean to `KeyboardInput.tick(boolean)` (`KeyboardInput.java:22-35`), which multiplies both impulses by the fixed float `0.3F`. No Swift Sneak definition or bonus helper exists in the checked enchantment sources. 1.19, Mojmap: `net/minecraft/client/player/LocalPlayer.java:739-740` supplies the clamped float bonus expression; `net/minecraft/world/item/enchantment/EnchantmentHelper.java:175-194` selects the maximum eligible equipped level and multiplies it by `0.15F`; `Enchantments.java:30` restricts Swift Sneak to the legs slot. This establishes the checked stable feature boundary between 1.18.2 and 1.19.

1.20.6, Mojmap: `net/minecraft/client/player/LocalPlayer.java:607-608,666-667` gates the input factor with `isMovingSlowly()` and passes `Mth.clamp(0.3F + EnchantmentHelper.getSneakingSpeedBonus(this), 0.0F, 1.0F)` to `Input.tick`; `net/minecraft/client/player/KeyboardInput.java:21-32` multiplies both float impulses by that factor inside the slow-movement branch. `net/minecraft/world/item/enchantment/EnchantmentHelper.java:150-169` selects the maximum Swift Sneak level in its eligible slots and returns that integer times `0.15F`; Swift Sneak is level 1–3 and leg-slot eligible in `net/minecraft/world/item/enchantment/Enchantments.java:102-107`.

1.21, Mojmap: `net/minecraft/client/player/LocalPlayer.java:603-605,663-664` casts `getAttributeValue(Attributes.SNEAKING_SPEED)` to `float` and passes it to the same gated keyboard-input scaling. `net/minecraft/world/entity/ai/attributes/Attributes.java:86-88` defines the attribute with a `0.3` default and `[0.0, 1.0]` range; `net/minecraft/world/entity/player/Player.java:232` includes it in player attributes; `net/minecraft/world/item/enchantment/Enchantments.java:563-585` defines Swift Sneak levels 1–3 as a leg-slot `ADD_VALUE` attribute effect of `LevelBasedValue.perLevel(0.15F)`.

Difference: The scalar changes from a float expression based on Swift Sneak's maximum equipped level, followed by an explicit float clamp, to an effective attribute value represented as `double` and cast to `float` at the LocalPlayer call site. In 1.21, `LevelBasedValue.Linear.calculate` computes the enchantment amount in float, `EnchantmentAttributeEffect.getModifier` widens it to double, and `AttributeInstance.calculateValue` adds it to the double base before the final caller cast. In both releases, keyboard impulses are scaled only when `LocalPlayer.isMovingSlowly()` is true (`isCrouching() || isVisuallyCrawling()`).

Movement meaning: With the default base 0.3 and ordinary vanilla Swift Sneak levels 0–3, both producers yield the same float scalars: `0.3F`, `0.45F`, `0.6F`, `0.75F`. This permits historical keyboard input production to cover ordinary Swift Sneak without claiming a trajectory difference from this producer alone. Nondefault attribute state can distinguish the producers: with base 0.5 and Swift Sneak I, 1.21 supplies `0.65F`, whereas the older expression supplies `0.45F`. Custom attribute production is not a pre-1.21 feature; this witness does not authorize replacing modern-only attribute effects for older profiles.
