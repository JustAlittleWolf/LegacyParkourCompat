## Scope and integration

Integrated against local main `64895d266fcee5da774c3236295ba949045200c7`. Adds one player-context collision-shape hook for the seven fences present in 1.8.9: the six wood fences and Nether Brick Fence. It restores the missing arm only for an adjacent End Portal Frame when the current fence side property is false. Existing side properties and post are included when the hook supplies a shape; otherwise the native shape is returned. No block state is changed.

Fence IDs are disjoint from the existing pane IDs and use the same versioned `BlockCollisionShape` provider. The existing `BlockStateCollisionShapeMixin` dispatches with `MovementRuntime.playerFrom(context)`, excluding non-player entities. `@MovementChange(emulates = V1_8)` keeps later historical profiles and CURRENT on native behavior. Passenger yaw, Elytra, swimming pitch, and sneak-edge changes remain present and separate.
