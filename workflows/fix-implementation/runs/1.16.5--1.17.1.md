## Dispositions

- **Jump Boost addition precision — implemented.** The discovery finding is source-confirmed on the local-player jump path. The 1.16.5 `LivingEntity.java` source hash is `B5D8A1A3C80F85D5D545B5A777E9E2A915DC002A7E31B5F5AD12BF7E285D7A88`; 1.17.1 is `33FD081AADB2B6FDC9EBF487DB6DA5B38C54F4B8676572790EE2203690D15E6F`. In 1.16.5, `jumpFromGround()` adds the float boost into a float local with `f += 0.1F * (amplifier + 1)`. In 1.17.1, `getJumpBoostPower()` returns the float product as a double and `jumpFromGround()` adds it to the float jump power as a double.
- **Version boundary — corroborated.** The 1.16.2 group base uses the same float compound assignment as 1.16.5; its `LivingEntity.java` hash is `B5D8A1A3C80F85D5D545B5A777E9E2A915DC002A7E31B5F5AD12BF7E285D7A88`. The 1.17 group base still uses the float compound assignment; its source hash is `8E81E5F1317D154FA41B676721FF581BADD46296F77BCEBCADB3C63448E528ED`. Therefore the precision change is within `(1.17, 1.17.1]`, and `V1_17_1` is the first supported enum boundary for the double behavior. All four historical sources came from ready Mojmap markers under `stable-shared-minecraft/ready/` and were rehashed before handoff.

- **Levitation unloaded-chunk minimum — not implemented.** The discovery catalog leaves this as a candidate because its consequence depends on server/datapack dimension-type data absent from the client artifacts. It is not evidence for movement an A-era map could specify.
