# 1.11.2–1.12.2 movement implementation draft

Status: buildable checkpoint; the `V1_11_2` boundary is verified against the 1.11.1 and 1.12 group-base sources. Revalidation of the 1.11.2 and 1.12.2 endpoint provenance from the stable staging area remains before final handoff.

The draft contains the three movement deltas currently supported by the 1.11.2 and 1.12.2 source comparison:

- Fall-flying uses the historical head-yaw rotation vector and reproduces the old float sine-table indexing.
- Beds do not apply the later bounce restitution when emulating the older behavior.
- Server-side pig and minecart dismount placement follows the older candidate-box and candidate-order behavior.

Each bridge is gated to `Player`, so the generic 26.2 hooks preserve vanilla behavior for non-player entities.

The exact 1.11.1 and 1.12 Feather sources confirm the transition at `V1_12`, so the old behavior belongs to the last older group, `V1_11_2`. In 1.11.1, `LivingEntity.getLookVector()` delegates to the head-yaw rotation path; `BedBlock` has no `beforeCollision` bounce override; and `dismountRider` checks a box moved upward by `1.0`. At 1.12, fall-flying uses the inherited body-yaw look vector, `BedBlock.beforeCollision` applies `0.66F` bounce, and `dismountRider` changes the box and checks it with a `0.0` vertical offset.
