## Bounded source delta

`Player` extends `LivingEntity` in A and B and defines no `knockback` override in either paired Player source. The inherited public response method changes how the `KNOCKBACK_RESISTANCE` attribute affects direct player movement:

- A `LivingEntity.knockback(Entity, float, double, double)`, lines 1195–1202, skips the response when `random.nextDouble() < resistance`; otherwise it sets `hasImpulse`, normalizes/scales the horizontal direction by the full supplied strength, halves existing X/Z velocity and subtracts that vector, and applies the grounded Y cap using the full strength.
- B `LivingEntity.knockback(float, double, double)`, lines 1319–1327, first scales the supplied strength by `(1.0 - resistance)`, then applies the same response when the resulting strength is positive. It sets `hasImpulse`, scales the horizontal direction by the reduced strength, halves/subtracts X/Z and applies the grounded Y cap using the reduced strength.

For equal positive input strength and an attribute value strictly between 0 and 1, A applies the full impulse probabilistically while B applies a reduced impulse deterministically. The claim is only the direct method response; it does not cover attack, damage, cause selection or another entity’s movement.
