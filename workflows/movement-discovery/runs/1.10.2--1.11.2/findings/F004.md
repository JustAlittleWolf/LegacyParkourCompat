# F004: Farmland conversion raises intersecting entities to dirt top

- Older A: 1.10.2
- Newer B: 1.11.2
- Mechanic / coverage slices: blocks and external influences; S5, S7
- Classification: changed behavior
- Confidence: source-confirmed
- Applicability: historical player behavior
- First changed release: unknown within (A, B]
- Runtime validation: not performed

## Paired evidence

A: `../../../../decompiled_minecraft/1.10.2/ornithe-feather/net/minecraft/block/FarmlandBlock.java`, `FarmlandBlock.tick`, `onFallenOn`, and `neighborChanged`, SHA-256 `63d9048ebed65b890c370a1da6e79733904f67d953aff9fd8c0316f97f9d4e7f`; conversion writes dirt directly.

B: `../../../../decompiled_minecraft/1.11.2/ornithe-feather/net/minecraft/block/FarmlandBlock.java`, `FarmlandBlock.setDirt(World,BlockPos)`, lines 71–79, SHA-256 `09e260528fd78b4bbdbc302726c7ae937fbc49f17b674c4a7ad802e0f7b6f5e8`; writes dirt, obtains its collision box and sets each intersecting entity's Y to box.maxY. Drying, trampling, neighbor and added callbacks call the helper.

## Source-level difference

On each listed farmland-to-dirt path, B explicitly relocates every entity returned in the replacement block collision box to the new collision top; A only replaces the block state.

## Reachability and dependencies

Player overlaps a farmland block as it converts to dirt -> block callback -> entity position update. Dirt has a full-block collision top. `onFallenOn` conversion is server-gated; this finding does not assert a local client independently performs authoritative relocation.

## Consequence and uncertainty

B sets the overlapping entity's vertical position to the block top, which can alter player position. Callback timing and synchronization effects are not runtime-tested.

## Handoff

Independent block conversion side effect. Scope to entity intersection at conversion. Other farmland conditions/callback reachability should be considered when implementing.
