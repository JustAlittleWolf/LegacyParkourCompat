# Candidate: splash-potion impact geometry changes Player movement-effect strength

- Finding ID: `F-SPLASH-POTION-MOVEMENT-EFFECT-AREA-1.21.5-1.21.8`
- Status: discarded; the changed path controls potion effect application, which is outside the movement-emulation scope. The direct Player movement consumers are unchanged.
- Slice routes: S6.2, S6.3, S7.2; inventories INV-MODIFIERS, INV-EXTERNAL, INV-EXCLUSIONS.
- A evidence: `AbstractThrownPotion#onHit()` passes the directly hit entity (or null on a block hit) to `onHitAsPotion()` (A lines 73-87). `ThrownSplashPotion#onHitAsPotion()` lines 39-75 searches an area around the potion's bounding box, computes distance to each LivingEntity position, gives a directly hit entity scale 1, and otherwise uses `1 - sqrt(distanceSquared)/4`; that scale changes instantaneous effect strength or non-instantaneous effect duration. Source SHA-256 `6f419c5dea90016d1a9cd3979fcb8cc66ba4939985f9d0cacc4108ae780003dd`.
- B evidence: `AbstractThrownPotion#onHit()` now passes the complete `HitResult` to the same server-only callback (B lines 70-84). `ThrownSplashPotion#onHitAsPotion()` lines 39-72 anchors the search box at `HitResult#getLocation()`, inflates each target bounding box by `ProjectileUtil.computeMargin(this)`, computes squared distance from the shifted impact box to that inflated bounding box, and applies one falloff formula without A's direct-hit special case. Source SHA-256 `3168671a37cec07823b31909a50149ba970d1bf9506a3596530750af06fe6758`.
- Player reachability: the callback enumerates `LivingEntity` targets, including Player, and applies every effect present in `PotionContents`. A/B `Potions.java` is source-identical (SHA-256 `8a302e47966eb4510c37405a02cc96130548f7ed4738cd0492ce0bd3db0f8ca7`) and includes built-in Speed, Slowness, Jump Boost and Slow Falling potion effects (A/B lines 23-39, 83-85). For a `PotionContents` list carrying one of these effects, the changed scale changes its applied duration; for an instantaneous movement effect, it changes applied effect strength. Jar resources and default item-component bindings remain outside this source-only boundary.
- Exact candidate precondition: a server-side splash potion carries a movement-relevant effect and hits an entity or block near a Player within the effect area, where the A center/direct-target scale and B impact-box/bounding-box scale differ. The resulting effect duration or strength then differs for that Player and can change subsequent movement. `AbstractThrownPotion#onHitAsWater()` is a separate unchanged path and is not part of this candidate.
- Disposition: This changes potion effect application geometry/state production; it does not change the direct Player movement numeric consumers. Per the audit scope, effect-state production remains excluded, so do not reconcile this delta as a player movement mechanic. Resource-backed item bindings remain uninspected.
- Artifact provenance: exact A/B Mojmap source manifests and readiness records are recorded in `run.md`; both cited source files were verified against those manifests. No derived mapped jar or bytecode inference is used.
