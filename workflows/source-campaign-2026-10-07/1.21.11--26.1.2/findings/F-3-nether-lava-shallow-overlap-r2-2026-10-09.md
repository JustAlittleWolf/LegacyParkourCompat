## Concrete vanilla fluid and player state

Use a Nether dimension in which the exact vanilla `DimensionTypes` sets FAST_LAVA=true. Build a supported, side-walled horizontal channel with flowing LAVA LEVEL states at `(100,64,100)` through `(106,64,100)` with amounts 1 through 7, and a LAVA source amount 8 at `(107,64,100)`. The source-to-current direction is east. The Nether drop-off is 1, and the exact `FlowingFluid.getNewLiquid()` chain constructs each non-falling level by subtracting one from its higher neighbor. Keep north, south and west of `(100,64,100)` as solid channel walls so empty neighboring fluid states add no fallback flow; leave the block above the level-1 cell empty. All scan coordinates can remain in a fully loaded chunk.

For the level-1 target cell, `getOwnHeight()` is `1.0F/9.0F`; the east level-2 cell contributes the horizontal difference `1.0F/9.0F - 2.0F/9.0F` in X, and the three solid-wall directions block empty-neighbor fallback. The exact paired `getFlow()` normalization therefore supplies the nonzero `(-1,0,0)` current to the player's one-cell scan. This is a concrete reachable fluid state and source-derived vector, not a hypothetical caller-supplied flow.

Set `h = 1.0F / 9.0F`, evaluated as a Java `float`. Define `topB = 64.0D + (double)h` and place a standing, unmounted, non-flying Player with X/Z `(100.5D,100.5D)` at `playerY = topB - 0.003D`, horizontal look direction and zero horizontal delta movement. Thus `topB = 64.11111111193895` and `playerY = 64.10811111193895` (decimal renderings of the exact Java double results). This deliberately forms the coordinate in double precision; it does not evaluate `64 + h` as float. The Player's `0.6F x 1.8F` box, deflated by `0.001D`, scans X/Z cell 100 and Y cells 64-65; only Y=64 contains tagged lava. The source and level-2 neighbor at X=101 remain outside the scan. The Player is pushed by fluid in both versions because `isPushedByFluid()` is `!abilities.flying`.

For B, the tracker measures from the raw entity box minimum. Its single-cell height is `topB - playerY = 0.0030000000000001137`; the accumulated current is `(-0.0030000000000001137,0,0)`, with squared length `9.000000000000683E-6 < 1.0E-5F` (the float cutoff is `9.999999747378752E-6`). The strict B cutoff returns before current averaging, lava-strength scaling, minimum impulse or `addDeltaMovement`.

A forms the fluid top by adding `int blockY + float fluidHeight`, so this operation rounds to float before widening: `topA = 64.11111450195312`. The A deflated box minimum is `playerY + 0.001D = 64.10911111193896`, giving one-cell overlap `topA - (playerY + 0.001D) = 0.002003390014166939`. A's Player path keeps its per-cell current, scales it by Nether FAST_LAVA strength `0.007`, and obtains magnitude `1.4023730099168574E-5`, strictly above Vec3's normalization floor `1.0E-5F`. With old X/Z zero, the subsequent strict minimum-impulse branch normalizes and scales this nonzero vector to `0.0045000000000000005` before adding it to Player delta movement. This uses one double-precision coordinate definition consistently while preserving A's source float-top operation and B's double fluid-bottom operation.
