## Source-level difference

Preconditions: server-side normal block update flags dispatch neighbor shape updates; a horizontal-facing Repeater or Comparator has a block directly below it that changes to a state whose UP face is not sturdy for `SupportType.RIGID`.

In A, the DOWN shape callback on a Repeater reaches the existing server axis-mismatch branch (Y differs from horizontal facing) and writes only its LOCKED property; a Comparator inherits the base `BlockBehaviour#updateShape` body, which returns its current state. Both remain in the world. In B, the new support guard in RepeaterBlock and the added guard in ComparatorBlock evaluate the supplied changed-neighbor state through `canSurviveOn`; when support fails either returns AIR. `Block.updateOrDestroy` removes either diode on the server. The support predicate is the same UP/RIGID face-sturdy condition on both endpoints; the difference is the new shape-update removal path.

The trigger is reachable from the common `Level#setBlock` path: when the state below changes, `BlockState#updateNeighbourShapes` visits the block above with a DOWN direction, and `LevelAccessor#neighborShapeChanged` calls `NeighborUpdater.executeShapeUpdate`. The cited `Level#setBlock` route dispatches shape updates; no separate `neighborChanged` callback is part of this bounded route. This finding does not claim behavior for an independently invoked `neighborChanged` event, whose inherited Diode survival check exists in both versions.

## Reachability and dependencies

World/block state change below a diode -> `updateNeighbourShapes` -> DOWN `neighborShapeChanged` -> the Repeater/Comparator `updateShape` callback -> retained diode in A / AIR and server removal in B -> `BlockCollisions.computeNext` consumes the retained/absent collision shape during `Entity.move`. A player whose movement box intersects or stands on a Repeater or Comparator can therefore encounter different movement collision geometry after the support update. Both blocks are existing vanilla blocks in A, so these are not modern-only blocks or states.

## Consequence and uncertainty

Source-proven: under the stated callback preconditions, A retains the Repeater or Comparator 1/8-block collision shape and B removes that collision shape from the world. Predicted: subsequent player collision clipping can differ where the movement box overlaps either diode. No final position, velocity, trajectory, or gameplay reproduction was measured. The exact support-changing action and any modded update policy are outside this source claim.

No first changed release inside the interval was inspected. No gameplay validation was performed.
