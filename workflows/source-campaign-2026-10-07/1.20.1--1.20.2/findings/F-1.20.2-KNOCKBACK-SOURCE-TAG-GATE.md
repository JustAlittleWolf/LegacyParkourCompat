- Older version A: 1.20.1
- Newer version B: 1.20.2
- Mechanic / coverage slice IDs: direct player knockback application; S12-PLAYER-KNOCKBACK-SOURCE-TAG-GATE; INV-EXTERNAL
- Classification: source-confirmed direct-motion gate difference with a vanilla-default fireworks case; runtime datapack/tag overrides remain unobserved
- Confidence: source-confirmed for the paired call-site, velocity writer, official server artifact hashes and packaged server tag values; runtime world tag state and trajectory not validated

- Runtime validation: not performed

## Source-level difference

For the same accepted-hit and non-null-attacker preconditions, A's generic LivingEntity#hurt path excludes sources carrying IS_EXPLOSION from this call to knockback; B replaces that predicate with NO_KNOCKBACK. The velocity-writing body itself is unchanged. Thus the source-confirmed difference is which tagged source categories reach the direct knockback writer, not knockback arithmetic or hit/damage production.

Player inherits the cited LivingEntity method on the server-side class hierarchy. The client LocalPlayer#hurt override returns false in both endpoints, so this finding does not claim local client damage prediction. The client motion handler can apply an addressed entity velocity through the common lerpMotion path. A separate ClientPacketListener#handleExplosion adds the explosion packet's vector to local-player delta movement on both endpoints; that independent packet path is not attributed to this changed hurt guard.

The vanilla server-jar defaults establish the FIREWORKS membership relevant to the changed predicate. A datapack or experimental pack can change those defaults, and a client may receive the resulting tag state through the server tag-update packet; neither a runtime datapack stack nor the synchronized payload was captured. The finding therefore claims only the packaged vanilla default case and does not establish a final client velocity or trajectory.

## Consequence and uncertainty

Source-proven: on the exact packaged vanilla server defaults, a fireworks source with a non-null causing entity reaches the shared direct delta-movement/impulse writer for a Player-derived LivingEntity in 1.20.2 and is filtered before that writer in 1.20.1. The identical writer performs the same knockback math when reached. Datapack/experimental tag overrides, synchronized runtime tag payloads, hit acceptance in a specific encounter, final client velocity and trajectory remain unestablished. Health, damage amounts, attack production and non-player motion are not claimed.

No first changed release inside the interval was inspected. No gameplay validation was performed.
