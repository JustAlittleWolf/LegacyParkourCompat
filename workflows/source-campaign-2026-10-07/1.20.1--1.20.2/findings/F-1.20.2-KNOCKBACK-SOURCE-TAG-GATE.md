## Source-level difference

For the same accepted-hit and non-null-attacker preconditions, A's generic LivingEntity#hurt path excludes sources carrying IS_EXPLOSION from this call to knockback; B replaces that predicate with NO_KNOCKBACK. The velocity-writing body itself is unchanged. Thus the source-confirmed difference is which tagged source categories reach the direct knockback writer, not knockback arithmetic or hit/damage production.

Player inherits the cited LivingEntity method on the server-side class hierarchy. The client LocalPlayer#hurt override returns false in both endpoints, so this finding does not claim local client damage prediction. The client motion handler can apply an addressed entity velocity through the common lerpMotion path. A separate ClientPacketListener#handleExplosion adds the explosion packet's vector to local-player delta movement on both endpoints; that independent packet path is not attributed to this changed hurt guard.

The exact contents of the client-jar defaults are recorded above, but the authoritative server tag-loading artifact and any datapack overrides are not available in this pair publication. This finding therefore does not assert that a named source takes the changed branch on a vanilla server or establish the server packet response for a named source. The guard difference is a conditional player-motion candidate for blind review; data-backed applicability remains open.

## Consequence and uncertainty

Source-proven: when the stated call-site conditions hold, the endpoint predicates differ before a shared method that directly writes delta movement and the impulse flag on a LivingEntity, including Player-derived server entities. Client-jar resources show a fireworks membership difference under packaged client defaults; authoritative server membership, final client velocity and trajectory remain unestablished. Health, damage amounts, attack production, non-player motion and runtime behavior are not claimed.
