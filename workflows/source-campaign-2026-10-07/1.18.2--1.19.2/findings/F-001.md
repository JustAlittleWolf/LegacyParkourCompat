# F-001: Swift Sneak raises local crouch/crawl input scale

- Status: source-confirmed
- Scope: local keyboard movement input; 1.18.2 is A and 1.19.2 is B.
- Preconditions / reachability: the local player is crouching or visually crawling (`LocalPlayer.isMovingSlowly()`), keyboard input is sampled, and the equipped leggings provide Swift Sneak. With no enchantment level, B retains the 0.3 scale.
- A behavior: `LocalPlayer.aiStep()` calls `input.tick(isMovingSlowly())`. `KeyboardInput.tick(boolean)` samples the directional, jump and shift keys and multiplies lateral and forward impulses by `0.3F` when slow movement is active.
- B behavior: `LocalPlayer.aiStep()` computes `Mth.clamp(0.3F + EnchantmentHelper.getSneakingSpeedBonus(this), 0.0F, 1.0F)` and passes the result to `KeyboardInput.tick(boolean,float)`. The helper returns the Swift Sneak level multiplied by `0.15F`; the enchantment is registered for `EquipmentSlot.LEGS` and has maximum level 3. Levels 1, 2 and 3 therefore scale slow input by 0.45, 0.60 and 0.75, respectively.
- State path: leggings/enchantment level -> helper bonus -> LocalPlayer pre-travel input factor -> `leftImpulse` and `forwardImpulse` -> local movement input consumers. `Entity.moveRelative()` and `getInputVector()` retain the same conversion math.
