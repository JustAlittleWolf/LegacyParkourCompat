# MC1204-1206-03: Player jump strength is attribute-backed in 1.20.6

- **1.20.4**, mojmap: `1.20.4/mojmap/net/minecraft/world/entity/LivingEntity.java`; lines 2000-2002.
- **1.20.6**, mojmap: `1.20.6/mojmap/net/minecraft/world/entity/LivingEntity.java`; lines 2057-2063.

## Difference

With the default 1.20.6 attribute value, multiplying `0.42F` by `1.0F` preserves the prior base factor before block jump factor and jump-boost addition. 1.20.4 has no player generic jump-strength input. 1.20.6's syncable attribute allows a non-default value to scale the base jump term, changing jump power and therefore the ground-jump velocity when it passes the cutoff in MC1204-1206-02.

## Movement meaning

Both normal ground-jump callers reach `LivingEntity.getJumpPower()`. 1.20.6 player instances include the new inherited attribute through `Player.createAttributes()`, and the paired client handler applies supplied values to the client attribute map.

The producer of a non-default value remains external and is not inferred here; applicability is explicitly conditional on the supplied value.

Source-proven: the 1.20.6 player jump path reads a generic, syncable jump-strength attribute; default value matches the prior hardcoded multiplier.

Non-default movement magnitude is conditional on the supplied value and block/effect terms.
